coddle
核心：两支。一是过分呵护：把人照顾得太周到，多带批评。
二是烹饪上的小火慢煮：coddled eggs 是嫩煮蛋。
① They coddle their students.
= 他们把学生护得太过。
coddle = 过分呵护
② He was coddled as a boy.
= 他小时候被宠得厉害。
be coddled = 被过分呵护
③ Coddled eggs are cooked gently.
= 嫩煮蛋是小火慢煮的。
coddled = 小火慢煮的
构词：可能与表示热饮的旧词 caudle 有关
注意语域：呵护那一支多带批评。

code
核心：五支。一是代码：编程写的指令，动词是编程，coded
是编了码的。二是密码。三是号码式的编码：a postal code
是邮政编码。四是规范与准则：a code of conduct 是行为
准则。五是暗语：speak in code 是话里有话。可数。
① She writes code all day.
= 她整天写代码。
write code = 写代码
② The message was in code.
= 那条讯息是加密的。
in code = 以密码形式
③ Enter the postal code.
= 输入邮政编码。
a postal code = 邮政编码
④ The firm has a code of conduct.
= 那家公司有行为准则。
a code of conduct = 行为准则
⑤ He was speaking in code.
= 他话里有话。
speak in code = 说得含蓄有暗指
⑥ The data is coded by region.
= 那些数据按地区编了码。
coded = 编了码的
⑦ The operation had the code name Overlord.
= 那次行动的代号是 Overlord。
a code name = 代号；code-named = 代号为……的
军事与警方用语；形容词形式常见于报道，如 a code-named operation。
⑧ Snowdrop was the code word for the retreat.
= 「雪花莲」是撤退的暗号。
a code word = 暗号；也指政治上讳饰的说法
第二义常见于评论：说某个词是 a code word for something，意思是拿它当幌子。
⑨ The industry has a code of practice on advertising.
= 那个行业有一套广告业务守则。
a code of practice = 业务守则
比法律松、比惯例紧：行业自订，成员自愿遵守，违反了多半没有法律后果。
⑩ The two airlines have a code-sharing agreement.
= 那两家航空公司有代码共享协议。
code-sharing = 代码共享（一个航班挂两家公司的班号）
航空业术语；订票时看到两个班号指同一架飞机，就是这回事。
⑪ Bilingual speakers do a lot of code-switching.
= 双语者经常在两种语言之间来回切换。
code-switching = 语码转换（说话中途换语言或语体）
语言学术语。这里的 code 指一套语言或语体，不是密码那个义。
⑫ The files are color coded by year.
= 那些文件按年份用颜色分类。
color code = 用颜色分类标记（美式拼法）
名词说 a color code，动词直接用它，过去分词 color-coded。
构词：拉丁语 codex 木简、法典
注意用法：代码与准则两支在今天的文字里最常读到。

codeine
核心：一种鸦片类止痛药，也用来止咳，常与别的药配成
复方。有依赖性，多数国家管制。不可数。
① The tablets contain codeine.
= 那些药片含可待因。
codeine = 可待因
② Codeine can be habit-forming.
= 可待因会形成依赖。
habit-forming = 会形成依赖的
构词：希腊语 kodeia 罂粟头
注意用法：医药与管制报道里常见。

codependency
核心：共依存：一段关系里两个人互相强化对方的问题行为，
最常说酒瘾、药瘾家庭里那种彼此拖住的模式。形容词与名词
都是 codependent。心理学与自助书里的词。不可数。
① The therapist named it codependency.
= 治疗师把那称作共依存。
codependency = 共依存
② They fell into a codependent pattern.
= 他们陷进了互相拖住的模式。
codependent = 共依存的
③ Codependents often deny the problem.
= 处在这种关系里的人常否认有问题。
a codependent = 处在共依存关系里的人
构词：由表示共同与依赖的两部分拼成
注意用法：心理学与自助书里的词。

codex
核心：手抄本：古代与中世纪装订成册的抄写文献，跟卷轴
相对。复数 codices。文献学与历史里的词。可数。
① The codex dates from the fourth century.
= 那部抄本是四世纪的。
a codex = 手抄本
② Codices replaced scrolls.
= 抄本取代了卷轴。
a scroll = 卷轴
③ The library holds three codices.
= 那家图书馆藏了三部抄本。
hold = 收藏
构词：拉丁语 codex 木简、书册
注意用法：复数是 codices。

codger
核心：老家伙：说上了年纪的男人，多说 an old codger，
带一点无奈的调笑，不算恶意但也不客气。英式偏多，
带旧气。可数。
① He is a cheerful old codger.
= 他是个挺乐呵的老家伙。
an old codger = 老家伙（调笑）
② Codgers gathered in the corner.
= 几个老头聚在角落。
gather = 聚集
构词：可能出自旧词 cadger
注意语域：调笑口气，正式场合不用。

codicil
核心：遗嘱附件：在原遗嘱之外另立的一份补充或修改文件，
跟原件一起生效。法律用词。可数。
① She added a codicil in March.
= 她三月加了一份遗嘱附件。
a codicil = 遗嘱附件
② The codicil changed one bequest.
= 那份附件改了一笔遗赠。
a bequest = 遗赠
③ Codicils must be witnessed too.
= 附件也要有见证。
be witnessed = 有见证人
构词：拉丁语 codicillus 小文书
注意用法：法律文书里的词。

codify
核心：把散着的规则整理成成文的一套：codify the law 是
把法律法典化，也说把惯例写成明文。名词 codification。
书面与法律用词。
① They codified the common law.
= 他们把普通法法典化了。
codify = 编成法典、整理成明文
② Custom was later codified.
= 那些惯例后来被写成明文。
be codified = 被写成成文规则
③ Codification took ten years.
= 法典化用了十年。
codification = 法典化
构词：由表示法典的那个词加表示使的词根
注意语域：书面与法律用词。

codpiece
核心：十五六世纪男装裤前那块鼓出来的遮布，有时垫得很
夸张。服饰史与舞台服装里的词。可数。
① The portrait shows a padded codpiece.
= 那幅像上是块垫过的遮布。
a codpiece = 男裤前的遮布
② Codpieces grew absurdly large.
= 那种遮布后来大得荒唐。
absurdly = 荒唐地
构词：旧词 cod 袋 加 piece 片
注意用法：服饰史与舞台服装里的词。

codswallop
核心：英式口语：胡说八道、废话，多说 a load of
codswallop。带轻蔑但语气不重，偏旧。不可数。
① That is a load of codswallop.
= 那全是胡说。
a load of codswallop = 一堆胡话
② He dismissed it as codswallop.
= 他说那是废话，不予理会。
dismiss as = 视为……而不理
构词：来历不确定，二十世纪的英式口语
注意语域：英式口语，带轻蔑但不重。

coed
核心：两支，都是美式。一是形容词：男女同校的，也说男女
混合的队与活动。二是名词：旧时指女子大学生，这个用法
今天被视为过时且带轻慢，避开。也拼 co-ed。
① The college went coed in 1970.
= 那所学院一九七零年开始男女同校。
coed = 男女同校的（美式）
② They joined a coed team.
= 他们加入了一支男女混合队。
a coed team = 男女混合队
构词：由表示共同与教育的两部分截短拼成
注意语域：名词义过时且带轻慢，避开。

coefficient
核心：系数：乘在变量前面的那个数，也指衡量某种性质的
比例数，the coefficient of friction 是摩擦系数。数学与
理工文字里的基本词。可数。
① The coefficient is negative.
= 那个系数是负的。
a coefficient = 系数
② Look up the coefficient of friction.
= 查一下摩擦系数。
the coefficient of friction = 摩擦系数
③ Each term has its own coefficient.
= 每一项有自己的系数。
a term = 项
构词：由表示共同与起作用的两部分拼成
注意用法：数学与理工文字里的基本词。

coelacanth
核心：矛尾鱼：一类曾被认为早已灭绝的古老鱼，上世纪三十
年代在南非近海被重新发现，因此成了活化石的代表。可数。
① A coelacanth was caught in 1938.
= 一九三八年捕到过一条矛尾鱼。
a coelacanth = 矛尾鱼
② The coelacanth was thought extinct.
= 那种鱼本以为早已灭绝。
be thought extinct = 被认为已灭绝
构词：希腊语的空心与刺，因鳍刺中空
注意用法：古生物与自然史文字里常读到。

coeliac
核心：英式拼法：腹腔的，最常读到的是 coeliac disease
乳糜泻，吃了含麸质的食物就伤肠道。美式写 celiac。
① Coeliac disease is lifelong.
= 乳糜泻是终身的。
coeliac disease = 乳糜泻
② She was diagnosed coeliac.
= 她确诊了乳糜泻。
be diagnosed coeliac = 确诊乳糜泻
构词：希腊语 koilia 腹腔
注意拼写：美式写 celiac。

coelurosaur
核心：一类体形轻巧的食肉恐龙：骨头中空、后肢长，鸟类就
是从这一支演化来的。古生物学的分类词。可数。
① Birds descend from coelurosaurs.
= 鸟类是从这一支恐龙来的。
a coelurosaur = 虚骨龙类恐龙
② Coelurosaurs had hollow bones.
= 那一类恐龙骨头中空。
hollow = 中空的
构词：希腊语的空心与蜥蜴
注意用法：古生物学的分类词。

coerce
核心：强迫：用威胁或压力逼人做事。名词 coercion，形容词
coercive。书面与法律用词，比 force 更强调施压。
① They coerced him into signing.
= 他们逼他签了字。
coerce somebody into = 逼某人做某事
② The confession was obtained by coercion.
= 那份口供是逼出来的。
coercion = 强迫、胁迫
③ Coercive control is now a crime.
= 强制性控制现在是犯罪。
coercive = 强制的
构词：拉丁语 coercere 约束
注意语域：书面与法律用词。

coeval
核心：同一时代的：说两样东西年代相同、同时存在，
coeval with 是与……同期。书面语，多见于学术写作。
① The two temples are coeval.
= 那两座神庙是同一时代的。
coeval = 同一时代的
② The layer is coeval with the eruption.
= 那一层跟那次喷发同期。
coeval with = 与……同期
构词：由表示共同与时代的两部分拼成
注意语域：书面，多见于学术写作。

coexist
核心：并存：两方在同一时间同一地方共处，多说互相容忍地
共处。名词 coexistence，peaceful coexistence 是和平
共处，冷战语境里的固定说法。
① The two species coexist here.
= 那两个物种在这儿并存。
coexist with = 与……并存
② Can the two systems coexist?
= 那两套制度能并存吗？
coexist = 并存
③ They spoke of peaceful coexistence.
= 他们讲的是和平共处。
peaceful coexistence = 和平共处
构词：由表示共同与存在的两部分拼成
注意用法：和平共处那个搭配是冷战语境里的固定说法。

coffee
核心：咖啡：豆、粉与冲出来的饮料都用这个词，说一杯时
可数。复合一族：coffee break 工间歇、coffee table 茶几、
coffee morning 是英式的募款茶会。习语 wake up and
smell the coffee 是清醒点、看清现实。
① She grinds her own coffee.
= 她自己磨咖啡。
coffee = 咖啡
② Two coffees, please.
= 请来两杯咖啡。
a coffee = 一杯咖啡
③ We took a coffee break.
= 我们歇了会儿喝咖啡。
a coffee break = 工间歇
④ Put it on the coffee table.
= 放在茶几上。
a coffee table = 茶几
⑤ Wake up and smell the coffee.
= 清醒点，看清现实。
wake up and smell the coffee = 认清现实
⑥ The church held a coffee morning.
= 教堂办了场上午的募款茶会。
a coffee morning = 募款茶会（英式）
这是英式的一种小型慈善活动：上午聚在一起喝咖啡、顺便募捐。
⑦ She ordered a white coffee.
= 她要了杯加奶咖啡。
a white coffee = 加奶咖啡（英式）
⑧ They met in a coffee house near the docks.
= 他们在码头附近一家咖啡馆碰面。
a coffee house = 咖啡馆（旧式、偏文雅）；a coffee shop = 咖啡店（日常说法）
指同一类地方，coffee house 带旧时文人聚谈的味道，今天日常都说 coffee shop。
⑨ The office got a new coffee machine.
= 办公室新添了台咖啡机。
a coffee machine = 咖啡机（英式常用）；a coffee maker = 咖啡机（美式常用）
同一样东西两个说法，英美各偏一个，不必细分。
⑩ She baked a coffee cake for the meeting.
= 她给会上烤了个咖啡蛋糕。
a coffee cake = 咖啡味蛋糕（英式）；配咖啡吃的甜点（美式）
同一个词两边指的东西不一样：英式是蛋糕本身有咖啡味，美式是佐咖啡的点心。
⑪ A spoonful of coffee essence goes into the icing.
= 糖霜里加一勺咖啡浓缩液。
coffee essence = 咖啡浓缩液（烘焙调味用）
瓶装的浓缩糖浆，做点心时用来上味，不是拿来冲着喝的。
⑫ The neighbours hold a coffee klatch every Tuesday.
= 邻居们每周二聚在一起喝咖啡聊天。
a coffee klatch = 边喝咖啡边闲聊的小聚（美式）
从德语借来的词，后半截那个成分是「闲话」；也拼作 coffee klatsch。
⑬ It ended up as a coffee-table book.
= 那本书最后做成了摆在茶几上的大开本画册。
a coffee-table book = 图多字少、供人随手翻的大开本画册
带一点贬义：暗示是拿来摆的，不是拿来读的。
构词：阿拉伯语 qahwa，经土耳其语进欧洲各语
注意用法：说一杯时可数。

coffer

建筑上的方格镶板，coffered ceiling 是格镶天花。可数。

= 公共财库空了。

coffin

a nail in the coffin = 一道致命打击

cog

a cog in the machine：说人只是庞大机器里一个无关紧要的
小齿轮。cogwheel 是齿轮。可数。
① A cog had sheared off.
= 一个齿被剪断了。
a cog = 齿轮上的齿
② He felt like a cog in the machine.
= 他觉得自己只是机器里的一个小齿轮。

= 那个齿轮带动滚筒。
a cogwheel = 齿轮

cogent
核心：论证有力、说得让人不能不服：说理由、论点与说法，

cogitate
核心：细想、琢磨：正式或半开玩笑地说在思考，cogitate on

cognac
核心：法国干邑地区按规定工艺蒸馏的葡萄白兰地：产地受
保护，别处的同类酒只能叫 brandy。不可数。
① He poured two cognacs.
= 他倒了两杯干邑。
cognac = 干邑白兰地
② Cognac is aged in oak.
= 干邑在橡木桶里陈放。
