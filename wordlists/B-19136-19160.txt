= 手术一个星期后，疼痛又出现了。

④ He helped me with the move, so I returned the favour by painting his kitchen.
= 他帮我搬家，我就帮他刷厨房作为回报。
return the favour = 回报好意
⑤ The jury returned a verdict of not guilty.
= 陪审团作出了无罪裁决。
return a verdict = 作出裁决
⑥ Everyone was waiting for her return from the hospital.
= 大家都在等她从医院回来。
somebody's return = 某人的归来
⑦ The investment gave them a good return in the first year.
= 那笔投资第一年就给他们带来了不错的收益。
a good return = 不错的收益
⑧ A return ticket to London costs forty pounds.
= 去伦敦的往返票四十英镑。
a return ticket = 往返票
⑨ She looked after the children, and in return he cooked dinner every night.
= 她照看孩子们，作为回报，他每天晚上做饭。
in return = 作为回报
⑩ When grandmother cut her birthday cake, we all wished her many happy returns of the day.
= 奶奶切生日蛋糕时，我们都祝她生日快乐、长命百岁。
many happy returns = 生日快乐
⑪ Once the plane had left the runway, they had passed the point of no return.
= 飞机一离开跑道，他们就到了无法回头的地步。
the point of no return = 无法回头的地步
⑫ The queen made a return visit to the country ten years later.

a return visit = 回访
