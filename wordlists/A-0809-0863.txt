但读音是 /juː/，所以用 a university。

upstairs
① She went upstairs.
= 她上楼了。
注意：upstairs 前面不加 to。
② The bathroom is upstairs.
= 卫生间在楼上。
反义词：
upstairs 楼上
downstairs 楼下
③ The upstairs room is empty.
= 楼上那间空着。
这里 upstairs 作形容词。
常用搭配：
go upstairs = 上楼
run downstairs = 跑下楼

usual
① It's warmer than usual.
= 比平常暖和。
than usual = 比平常
② As usual, he was late.
= 像往常一样，他迟到了。
as usual = 照例
词族：
usually = 通常（副词）
unusual = 不寻常的
③ Business as usual.
= 一切照常。
常用搭配：
the usual = 老样子（点单时常用）
more than usual = 比平常多

valley
① The village is in a valley.
= 那个村子在山谷里。
这里：
valley = 山谷
② The river runs through the valley.
= 河流穿过山谷。
地形词：
mountain 山 / valley 谷
hill 丘 / plain 平原
③ They farm in the valley.
= 他们在山谷里种地。
常见地形：
valley 山谷 / canyon 峡谷
hill 小山 / cliff 悬崖

value
① What's the value of this?
= 这个值多少钱？
这里：
value = 价值
② I value your advice.
= 我很看重你的建议。
这里是动词：
value = 重视
词族：
valuable = 贵重的
③ It has sentimental value.
= 它有纪念意义。
常用搭配：
good value for money = 物有所值
value for money = 性价比
