function
核心：四支。一是功能、作用：the function of something；
二是职责：perform a function；三是（正式的）活动、场合：a school function；
四是（数学）函数：a function of x。
① The function of that lever is printed on a label nobody has read.
= 那根杆的功能印在一张没人读过的标签上。
the function of something = 某物的功能
② She performs a function that three people used to share.
= 她一个人担着从前三个人分担的职责。
perform a function = 履行职责
③ A school function on a Friday empties the staff room by four.
= 周五的校内活动，四点就让教员室空了。
a school function = 校内活动
④ Output is a function of temperature and nothing else here matters.
= 产量是温度的函数，这里别的都不要紧。
a function of something = 某物的函数
function as = 充当、起…作用
function key = 功能键
function word = 功能词

functional
核心：三支。一是能用的、正常运转的：a functional lift；
二是（设计）实用为先的：functional furniture；三是（医学、语言学）功能性的。
副词 functionally 并入本条。
① Only one lift is functional and it stops at the wrong floors.
= 只有一部电梯能用，还停错楼层。
a functional lift = 能正常运转的电梯
② Functional furniture in that flat means nothing you would sit on twice.
= 那套公寓里所谓实用的家具，都是不想坐第二回的。
functional furniture = 实用为先的家具
③ The scan is normal and the problem is called functional.
= 影像是正常的，那个问题被称作功能性的。
a functional disorder = 功能性障碍
副词 functionally：在功能上。
④ The two machines are functionally the same and cost twice as different.
= 那两台机器功能上一样，价钱差了一倍。
be functionally the same = 功能上相同
functional food = 功能食品
functional grammar = 功能语法

functionalism
核心：三支。一是（建筑、设计）功能主义，形式服从用途；
二是（社会学）功能主义理论；三是（语言学）功能主义路子。
① Functionalism gave that town four buildings and no shade at all.
= 功能主义给那座城留下四栋楼，一点树荫也没有。
functionalism = 功能主义
② Functionalism explains what a custom does and not how it started.
= 功能主义解释一项风俗起什么作用，不解释它怎么来的。
functionalism = 功能主义理论
③ He teaches functionalism to students who find it cold.
= 他给一群觉得它冷冰冰的学生讲功能主义。
teach functionalism = 讲授功能主义

functionalist
核心：三支。一是功能主义者；二是形容词性，功能主义的：a functionalist reading；
三是（建筑）走这一路的设计师。
① A functionalist asks what a thing is for before asking what it means.
= 功能主义者先问一样东西是干什么用的，再问它是什么意思。
a functionalist = 功能主义者
② A functionalist reading of that ritual leaves out everybody's feelings.
= 对那项仪式的功能主义解读，把所有人的感受都撇开了。
a functionalist reading = 功能主义解读
③ Two functionalists designed the estate and neither lived in it.
= 两位功能主义建筑师设计了那片小区，谁也没住进去。
functionalists = 功能主义建筑师

functionality
核心：三支。一是（软件、设备的）功能、可用的特性：add functionality；
二是能用性、可运转的程度；三是（设计的）实用性。
① They add functionality every quarter and remove nothing.
= 他们每季度加功能，什么都不删。
add functionality = 增加功能
② Half the functionality disappears when the connection drops.
= 一断线，一半的功能就没了。
lose functionality = 功能失效
③ The functionality of that kitchen beats anything it looks like.
= 那间厨房的实用程度，比它看上去强得多。
the functionality of something = 某物的实用程度

functionary

② The job is that of a functionary and the title says director.

functionaries = 公职人员

functor
核心：三支。一是（数学）函子，范畴之间保持结构的映射；
二是（编程）可映射的那类结构；三是（语言学）功能词。
① A functor carries the structure across and not just the objects.
= 函子搬过去的不只是对象，还有结构本身。
a functor = 函子
② The library treats any mappable type as a functor.
= 那个库把任何可映射的类型都当作函子处理。
a functor = 可映射的结构
③ Functors in that sense are the words that carry no meaning alone.
= 在那个意义上，功能词指的是单独不带意义的词。
a functor = 功能词

三是（音乐、物理）基频。副词 fundamentally 并入本条。

③ Fundamentalism grows fastest where the old answers stopped working.
= 老答案失灵的地方，原教旨主义长得最快。
fundamentalism grows = 原教旨主义扩张
