assign
核心：底层是"分派下去"。分派任务、分派人手、分派资源都是它。
被动式在正式文体里极常见。介词用 to。
① The teacher assigned homework.
= 老师布置了作业。
② He was assigned to the project.
= 他被分派到那个项目。
be assigned to = 被派到
③ They assigned her a new office.
= 他们给她安排了新办公室。
assign someone something = 分给某人某物
④ Assign a value to each item.
= 给每一项赋一个值。
assign a value to = 赋值给
词族：
assignment = 任务、作业

assignation
核心：指秘密的"幽会"，多带暧昧或阴谋色彩，
文学用语。另有法律上的"财产转让"义。
① They arranged an assignation.
= 他们安排了一次密会。
arrange an assignation = 约定幽会
② The assignation was discovered.
= 那次幽会被发现了。
③ The assignation of rights was legal.
= 权利的转让是合法的。
词族：
assign = 分派
注意区别：
assignation = 幽会（暧昧）
assignment = 任务、作业（中性）
两个词只差几个字母，语域天差地别。

assignment

② It takes time to assimilate new facts.
= 消化新信息需要时间。

= 那种文化同化了外来者。
词族：

注意语用：说少数族群 assimilate
在当代讨论里有争议，
更中性的说法是 integrate。

assimilation

常与 integration（各方互相适应）对举。

assist
核心：正式的"协助"，比 help 书面。结构：assist someone with
something 或 assist someone in doing。注意 in 后面接 doing，
不接动词原形。
① She assisted me with the report.
= 她协助我做那份报告。
assist someone with = 协助某人做某事
② He assisted in organizing the event.
= 他协助组织了那次活动。
assist in doing = 协助做
③ Nurses assist the surgeon.
= 护士协助外科医生。
④ Can I assist you?
= 需要帮忙吗？
词族：
assistance = 协助
assistant = 助手
近义对照：
assist 协助（正式）
help 帮助（通用）
aid 援助（正式，多指物资）
⑤ Assisted dying remains illegal there.
= 在那里协助死亡仍属违法。
assisted dying = 协助死亡
assisted suicide = 协助自杀
⑥ She moved into assisted living.
= 她住进了协助生活式养老社区。
assisted living = 协助生活（半自理养老模式）
⑦ Factories opened in the assisted areas.
= 工厂开在了受扶持地区。
assisted area = 受政府扶持的地区

assistance

assistant
核心：从 assist（帮忙）来，指"打下手的人"。这个词的用法值得单记的
不是意思，而是两个位置：单用是名词"助手"；放在职位名前面就成了
定语"副的、助理的"，assistant manager 是副经理，不是"经理的助手"。
英美的职级切法不同：英式的 shop assistant 是店员，美式学界的
assistant professor 是终身轨的最低一级，不是"教授的助手"。
① She is my assistant.
= 她是我的助手。
名词单用。
② He is assistant manager.
= 他是副经理。
assistant manager = 副经理

③ A shop assistant helped us.
= 一名店员帮了我们。
shop assistant = 店员（英式）
注意地域：美式说 sales clerk。
④ She is an assistant professor.
= 她是助理教授。
assistant professor = 助理教授（美式，终身轨最低一级）
⑤ The assistant referee raised the flag.
= 助理裁判举了旗。
assistant referee = 助理裁判（即边裁）
⑥ Ask the virtual assistant.
= 问问那个语音助手。
virtual assistant = 虚拟助手
今天这个搭配多指软件，不指人。
⑦ He won a research assistantship.
= 他拿到了研究助理的岗位与津贴。
assistantship = 助理职位（含津贴的研究生岗）
词族：
assist = 协助
assistance = 协助、援助

assize
核心：英国旧时的"巡回法庭"——法官定期到各郡开庭审重案，
一年几次，会期本身也叫这个词。多用复数 assizes。
一九七二年被 Crown Court 取代，此后只用于历史语境。
① The judge came for the spring assizes.
= 法官来主持春季巡回庭。
the spring assizes = 春季巡回审
② Murder cases went to the assizes.
= 命案要送巡回法庭审。
③ The assizes were abolished in 1972.
= 巡回法庭一九七二年被废止。
注意用法：
多用复数。
注意语域：
英国法制史用语，制度已废。

assizes

assonance
核心：修辞术语，指相邻词里元音相同而辅音不同，
如 "the rain in Spain"。和押头韵、押尾韵都不同。
① The poem uses assonance.
= 那首诗用了谐元韵。
② Assonance creates a soft echo.
= 谐元韵造成柔和的回响。
③ Note the assonance in that line.
= 注意那行里的元音呼应。
押韵三类：
alliteration = 头韵（词首辅音相同）
assonance = 谐元韵（元音相同）
consonance = 谐辅韵（辅音相同）
rhyme = 押韵（词尾整体相同）
