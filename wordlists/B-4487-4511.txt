clapboard
核心：美式的墙板：一块块横搭、上缘薄下缘厚的木板，把
外墙一层层盖住，新英格兰的白色木屋就是它。英式说
weatherboard。不可数。
① The house is white clapboard.
= 那栋房子是白色木墙板的。
clapboard = 横搭墙板（美式）
② Clapboard needs repainting often.
= 那种墙板要常重刷。
repaint = 重新刷漆
③ British builders say weatherboard.
= 英国的建筑工说另一个词。
weatherboard = 横搭墙板（英式）
构词：由表示拍打与板的两个词拼成
注意用法：美式；英式说 weatherboard。

claptrap
核心：空话废话：听着煞有介事、其实没内容的说法，带明显
的贬义。本指戏台上专为博掌声硬加的花腔。不可数。
① The speech was pure claptrap.
= 那篇讲话纯是空话。
claptrap = 哗众取宠的空话
② Don't believe that claptrap.
= 那种废话别信。
believe = 相信
③ The word once meant a stage trick.
= 那个词本指戏台上的花招。
a stage trick = 戏台上的花招
构词：由表示鼓掌与机关的两个词拼成
注意语域：明显带贬义。

claque
核心：捧场队：受雇在剧场里带头鼓掌喝彩的一伙人；引申指
一个人身边只会捧的随从。法语来的词，带贬义。可数。

③ The practice began in Paris theatres.
= 那套做法起于巴黎的剧院。
practice = 做法
构词：法语 claquer 鼓掌
注意语域：带贬义。

claret

年来专用这个词指那一带的红酒。二是那种深红偏紫的颜色。
不可数。

claret = 波尔多红葡萄酒（英式）

chiefly = 主要

注意用法：主要是英式说法。

clarify
核心：两支。一是说清楚：把含糊的地方讲明白。二是把液体
澄清：滤掉杂质，clarified butter 是澄清黄油。名词

clarinet

a clarinettist = 单簧管手
构词：法语 clarinette，出自表示清亮的那个词

clarity

clarity of thought = 思路清明
构词：拉丁语 clarus 清楚
注意用法：三支都不可数。

clash

clasp

class

classroom 教室、classwork 课堂作业、classless 无阶级的、

claymore
核心：两支。一是苏格兰高地的双手大剑：刃宽柄长，历史与
文学里的兵器名。二是现代的定向反步兵地雷，因形似得名。
可数。
① The claymore needed both hands.
= 那把大剑要双手才使得动。
a claymore = 苏格兰双手大剑
② Claymores hung in the hall.
= 大厅里挂着几把大剑。
hang = 挂着
③ A claymore mine faces one way.
= 那种地雷只朝一个方向炸。
a claymore mine = 定向反步兵雷
构词：盖尔语 claidheamh mor 大剑
注意用法：历史兵器与现代军械两义都读得到。

clean
核心：五支。一是干净的。二是动词的打扫、清洗，clean up
是收拾干净也引申成整顿。三是清白没污点的：a clean
record 是没有前科，come clean 是全都说出来。四是利落
一气呵成的：a clean break 是干净的了断，a clean sheet
是英式足球的零封。五是不带脏话与色情的。派生：cleaner
清洁工与清洁剂、cleaning 打扫、cleanly 利落地。
① The kitchen is spotlessly clean.
= 厨房干净得一尘不染。
clean = 干净的
② Clean the windows first.
= 先擦窗户。
clean = 打扫、清洗
③ They cleaned up after the party.
= 聚会后他们收拾干净了。
clean up = 收拾干净；也指整顿
④ He has a clean record.
= 他没有前科。
a clean record = 无前科的记录
⑤ You had better come clean.
= 你还是全说出来吧。
come clean = 全都说出来
⑥ They made a clean break.
= 他们断得干净。
a clean break = 干净的了断
⑦ The keeper kept a clean sheet.
= 门将保持零封。
a clean sheet = 零封（英式足球）
⑧ Keep the jokes clean.
= 玩笑别开荤的。
clean = 不带脏话与色情的
⑨ The cleaner comes on Fridays.
= 清洁工周五来。
a cleaner = 清洁工；清洁剂
⑩ Cleaning took all morning.
= 打扫花了一上午。
cleaning = 打扫
⑪ The bone snapped cleanly.
= 那根骨头断得很利落。
cleanly = 利落地
⑫ She lifted a hundred kilos in the clean and jerk.
= 她挺举举起一百公斤。
the clean and jerk = 挺举
举重的两个项目名都借了这个词的利落那一支。
⑬ He has a clean-cut look.
= 他看着干净利落。
clean-cut = 样子端正利落的
⑭ Clean down the surfaces after use.
= 用完把台面擦净。
clean down = 彻底擦净
⑮ Clean eating became a trend.
= 清净饮食成了风潮。
clean eating = 清净饮食（多带营销色彩）
近十年的健康营销词，不是营养学术语。
⑯ They cleaned the mud from the boots.
= 他们把靴子上的泥清掉了。
clean from = 把……从某处清掉
⑰ A clean-limbed young athlete led the parade.
= 一位身形匀称的年轻运动员走在前面。
clean-limbed = 身形匀称的（旧）
⑱ He is a clean-living man.
= 他生活规矩。
clean-living = 生活规矩的
⑲ Clean off the label first.
= 先把标签清掉。
clean off = 清除掉
⑳ They cleaned out the shed.
= 他们把棚子清空了。
clean out = 清空；也指把人的钱掏光
短语动词跟 off / out / down 搭，方向决定意思。
㉑ He arrived clean-shaven.
= 他来时脸刮得干干净净。
clean-shaven = 脸刮净不留须的
构词：古英语 clæne
注意用法：come clean 与 a clean sheet 都很常读到。
