coda
核心：两支。一是乐曲的尾声：正文结束后加的那一段收尾。
二是引申指一件事或一本书的收尾部分，这一支在书评里常
读到。可数。
① The coda repeats the theme slowly with the violins muted.
= 尾声把主题慢慢再奏一遍，小提琴上了弱音器。
a coda = 乐曲尾声
② The last chapter is a coda set thirty years after the rest.
= 最后一章是个收尾，写的是三十年后的事。
a coda = 收尾部分
③ The trip was a coda to a year nobody wanted to repeat.
= 谁都不想再过一遍那一年，那趟旅行是它的收尾。
a coda to = ……的收尾
构词：意大利语 coda 尾巴
注意用法：引申义在书评里常读到。

coddle
核心：两支。一是过分呵护：把人照顾得太周到，多带批评。
二是烹饪上的小火慢煮：coddled eggs 是嫩煮蛋。
① They coddle their students and act surprised when nobody argues back.
= 他们把学生护得太过，没人敢顶嘴时又装作意外。
coddle = 过分呵护
② He was coddled as a boy and never once carried his own bag.
= 他小时候被宠得厉害，包从来没自己拎过。
be coddled = 被过分呵护
③ Coddled eggs are cooked gently in a cup set in hot water.
= 嫩煮蛋是装在小杯里坐着热水慢慢煮的。
coddled = 小火慢煮的
构词：可能与表示热饮的旧词 caudle 有关
注意语域：呵护那一支多带批评。

code
核心：五支。一是代码：编程写的指令，动词是编程，coded
是编了码的。二是密码。三是号码式的编码：a postal code
是邮政编码。四是规范与准则：a code of conduct 是行为
准则。五是暗语：speak in code 是话里有话。可数。
① She writes code all day and has not read a novel since university.
= 她整天写代码，大学以后没读过一本小说。
write code = 写代码
② The message was in code and took the whole department a week to read.
= 那条消息是加密的，整个部门读了一周。
in code = 以密码形式
③ Enter the postal code and the rest of the address fills itself in.
= 输入邮政编码，地址其余部分会自动填好。
a postal code = 邮政编码
④ The firm has a code of conduct that nobody has been asked to read.
= 公司有行为准则，却没人被要求读过。
a code of conduct = 行为准则
⑤ He was speaking in code and half the room understood him perfectly.
= 他说的是隐语，屋里一半人完全听得懂。
speak in code = 说得含蓄有暗指
⑥ The data is coded by region and the codes were changed without notice.
= 数据按地区编码，而编码不打招呼就改了。
coded = 编了码的
⑦ The operation had the code name Overlord and was known to far too many.
= 这次行动代号「霸王」，知情的人多得离谱。
a code name = 代号；code-named = 代号为……的
军事与警方用语；形容词形式常见于报道，如 a code-named operation。
⑧ Snowdrop was the code word for the retreat and was never used.
= 「雪花莲」是撤退的暗号，一次也没用上。
a code word = 暗号；也指政治上讳饰的说法
第二义常见于评论：说某个词是 a code word for something，意思是拿它当幌子。
⑨ The industry has a code of practice on advertising and breaks it weekly.
= 这个行业有广告业务守则，每周都违反一次。
a code of practice = 业务守则
比法律松、比惯例紧：行业自订，成员自愿遵守，违反了多半没有法律后果。
⑩ The two airlines have a code-sharing agreement and blame each other for delays.
= 两家航空公司有代码共享协议，误点时互相推诿。
code-sharing = 代码共享（一个航班挂两家公司的班号）
航空业术语；订票时看到两个班号指同一架飞机，就是这回事。
⑪ Bilingual speakers do a lot of code-switching without noticing they do it.
= 双语者常常语码转换，自己却没察觉。
code-switching = 语码转换（说话中途换语言或语体）
语言学术语。这里的 code 指一套语言或语体，不是密码那个义。
⑫ The files are color coded by year and the yellow ones are missing.
= 文件按年份用颜色编码，黄色那批不见了。
color code = 用颜色分类标记（美式拼法）
名词说 a color code，动词直接用它，过去分词 color-coded。
构词：拉丁语 codex 木简、法典
注意用法：代码与准则两支在今天的文字里最常读到。

codeine
核心：一种鸦片类止痛药，也用来止咳，常与别的药配成
复方。有依赖性，多数国家管制。不可数。
① The tablets contain codeine and cannot be taken with the other ones.
= 那些药片含可待因，不能跟另一种一起吃。
codeine = 可待因
② Codeine can be habit-forming and is behind the counter here.
= 可待因会形成依赖，在这里要柜台后面才拿得到。
habit-forming = 会形成依赖的
构词：希腊语 kodeia 罂粟头
注意用法：医药与管制报道里常见。

codependency
核心：共依存：一段关系里两个人互相强化对方的问题行为，
最常说酒瘾、药瘾家庭里那种彼此拖住的模式。形容词与名词
都是 codependent。心理学与自助书里的词。不可数。
① Codependency kept them together through four attempts to stop drinking.
= 四次戒酒都没成，是共依存把他们绑在一起。
codependency = 共依存
② They fell into a codependent pattern where each excused the other.
= 他们陷进了互相拖住的模式，彼此替对方开脱。
codependent = 共依存的
③ Codependents often deny the problem and describe themselves as helping.
= 处在这种关系里的人常否认有问题，说自己是在帮忙。
a codependent = 处在共依存关系里的人
构词：由表示共同与依赖的两部分拼成
注意用法：心理学与自助书里的词。

codex
核心：手抄本：古代与中世纪装订成册的抄写文献，跟卷轴
相对。复数 codices。文献学与历史里的词。可数。
① The codex dates from the fourth century and is missing its first leaf.
= 那部抄本是四世纪的，第一页已经不在了。
a codex = 手抄本
② Codices replaced scrolls because you can turn to a page.
= 抄本取代了卷轴，因为它能直接翻到某一页。
a scroll = 卷轴
③ The library holds three codices and shows one at a time.
= 那家图书馆藏了三部抄本，一次只展出一部。
hold = 收藏
构词：拉丁语 codex 木简、书册
注意用法：复数是 codices。

codger
核心：老家伙：说上了年纪的男人，多说 an old codger，
带一点无奈的调笑，不算恶意但也不客气。英式偏多，
带旧气。可数。
① He is a cheerful old codger and knows everyone on the street.
= 他是个挺乐呵的老家伙，街上谁都认识。
an old codger = 老家伙（调笑）
② Codgers gathered in the corner and finished the crossword between them.
= 几个老头聚在角落，合力把填字做完了。
gather = 聚集
构词：可能出自旧词 cadger
注意语域：调笑口气，正式场合不用。

codicil
核心：遗嘱附件：在原遗嘱之外另立的一份补充或修改文件，
跟原件一起生效。法律用词。可数。
① She added a codicil in March and told nobody about it.
= 她三月加了一份遗嘱附件，没跟任何人说。
a codicil = 遗嘱附件
② The codicil changed one bequest and left the rest untouched.
= 那份附件改了一笔遗赠，其余一字未动。
a bequest = 遗赠
③ Codicils must be witnessed too, or the whole change falls away.
= 附件也要有见证人，否则整项改动作废。
be witnessed = 有见证人
构词：拉丁语 codicillus 小文书
注意用法：法律文书里的词。

codify
核心：把散着的规则整理成成文的一套：codify the law 是
把法律法典化，也说把惯例写成明文。名词 codification。
书面与法律用词。
① They codified the common law into a single volume of eight hundred pages.
= 他们把普通法法典化，编成八百页的一卷。
codify = 编成法典、整理成明文
② Custom was later codified and lost most of its exceptions.
= 那些惯例后来被写成明文，例外也丢了大半。
be codified = 被写成成文规则
③ Codification took ten years and three committees.
= 法典化用了十年，换了三个委员会。
codification = 法典化
构词：由表示法典的那个词加表示使的词根
注意语域：书面与法律用词。

codpiece
核心：十五六世纪男装裤前那块鼓出来的遮布，有时垫得很
夸张。服饰史与舞台服装里的词。可数。
① The portrait shows a padded codpiece and a very small dog.
= 那幅像上是块垫过的遮布，还有一只很小的狗。
a codpiece = 男裤前的遮布
② Codpieces grew absurdly large and then vanished within a generation.
= 那种遮布后来大得荒唐，一代人之内又销声匿迹。
absurdly = 荒唐地
构词：旧词 cod 袋 加 piece 片
注意用法：服饰史与舞台服装里的词。

codswallop
核心：英式口语：胡说八道、废话，多说 a load of
codswallop。带轻蔑但语气不重，偏旧。不可数。
① That is a load of codswallop and he knows it perfectly well.
= 那全是胡说，他自己心里清楚得很。
a load of codswallop = 一堆胡话
② He dismissed the whole report as codswallop without opening it.
= 整份报告他连翻都没翻，就说是废话。
dismiss as = 视为……而不理
构词：来历不确定，二十世纪的英式口语
注意语域：英式口语，带轻蔑但不重。

coed
核心：两支，都是美式。一是形容词：男女同校的，也说男女
混合的队与活动。二是名词：旧时指女子大学生，这个用法
今天被视为过时且带轻慢，避开。也拼 co-ed。
① The college went coed in 1970 and doubled its applications.
= 那所学院一九七零年开始男女同校，申请人数翻了一倍。
coed = 男女同校的（美式）
② They joined a coed team and won nothing for three seasons.
= 他们加入了一支男女混合队，三个赛季一场没赢。
a coed team = 男女混合队
构词：由表示共同与教育的两部分截短拼成
注意语域：名词义过时且带轻慢，避开。

coefficient
核心：系数：乘在变量前面的那个数，也指衡量某种性质的
比例数，the coefficient of friction 是摩擦系数。数学与
理工文字里的基本词。可数。
① The coefficient is negative, so the line falls as you go right.
= 那个系数是负的，所以线往右是下降的。
a coefficient = 系数
② Look up the coefficient of friction for rubber on wet tile.
= 查一下橡胶对湿瓷砖的摩擦系数。
the coefficient of friction = 摩擦系数
③ Each term has its own coefficient and the first one is hidden.
= 每一项有自己的系数，第一项那个是省略掉的。
a term = 项
构词：由表示共同与起作用的两部分拼成
注意用法：数学与理工文字里的基本词。

coelacanth
核心：矛尾鱼：一类曾被认为早已灭绝的古老鱼，上世纪三十
年代在南非近海被重新发现，因此成了活化石的代表。可数。
① A coelacanth was caught in 1938 and the museum kept the skin.
= 一九三八年捕到过一条矛尾鱼，博物馆把鱼皮留了下来。
a coelacanth = 矛尾鱼
② The coelacanth was thought extinct for sixty million years.
= 矛尾鱼一度被认为已经灭绝了六千万年。
be thought extinct = 被认为已灭绝
构词：希腊语的空心与刺，因鳍刺中空
注意用法：古生物与自然史文字里常读到。

coeliac
核心：英式拼法：腹腔的，最常读到的是 coeliac disease
乳糜泻，吃了含麸质的食物就伤肠道。美式写 celiac。
① Coeliac disease is lifelong and the only treatment is the diet.
= 乳糜泻是终身的，唯一的治法就是忌口。
coeliac disease = 乳糜泻
② The blood test only works if you are still eating gluten, coeliac or not.
= 无论是不是乳糜泻，那项血检都得在还吃着麸质时做才有效。
be diagnosed coeliac = 确诊乳糜泻
构词：希腊语 koilia 腹腔
注意拼写：美式写 celiac。

coelurosaur
核心：一类体形轻巧的食肉恐龙：骨头中空、后肢长，鸟类就
是从这一支演化来的。古生物学的分类词。可数。
① Birds descend from coelurosaurs and kept the wishbone and the hollow bones.
= 鸟类是从虚骨龙类来的，叉骨和中空的骨头都留了下来。
a coelurosaur = 虚骨龙类恐龙
② Several coelurosaurs are now known to have carried feathers for warmth.
= 已知有好几种虚骨龙类长着羽毛保暖。
hollow = 中空的
构词：希腊语的空心与蜥蜴
注意用法：古生物学的分类词。

coerce
核心：强迫：用威胁或压力逼人做事。名词 coercion，形容词
coercive。书面与法律用词，比 force 更强调施压。
① They coerced him into signing by threatening his brother's job.
= 他们拿他弟弟的饭碗施压，逼他签了字。
coerce somebody into = 逼某人做某事
② The confession was obtained by coercion and thrown out at trial.
= 那份口供是逼出来的，庭上不予采纳。
coercion = 强迫、胁迫
③ Coercive control is now a crime even where nobody was struck.
= 就算没动过手，强制性控制现在也是犯罪。
coercive = 强制的
构词：拉丁语 coercere 约束
注意语域：书面与法律用词。

coeval
核心：同一时代的：说两样东西年代相同、同时存在，
coeval with 是与……同期。书面语，多见于学术写作。
① The two temples are coeval and were probably built by one workshop.
= 那两座神庙是同一时代的，多半出自同一个作坊。
coeval = 同一时代的
② The ash layer is coeval with the eruption and dates the whole site.
= 那层灰跟那次喷发同期，整个遗址的年代就靠它定。
coeval with = 与……同期
构词：由表示共同与时代的两部分拼成
注意语域：书面，多见于学术写作。

coexist
核心：并存：两方在同一时间同一地方共处，多说互相容忍地
共处。名词 coexistence，peaceful coexistence 是和平
共处，冷战语境里的固定说法。
① The two species coexist here because they feed at different hours.
= 那两个物种在这儿并存，因为觅食的时段不同。
coexist with = 与……并存
② Can the two systems coexist in one building for a whole year?
= 那两套制度在同一栋楼里能并存一整年吗？
coexist = 并存
③ They spoke of peaceful coexistence and went on testing bombs.
= 他们讲着和平共处，一边照样试爆。
peaceful coexistence = 和平共处
构词：由表示共同与存在的两部分拼成
注意用法：和平共处那个搭配是冷战语境里的固定说法。

coffee
核心：咖啡：豆、粉与冲出来的饮料都用这个词，说一杯时
可数。复合一族：coffee break 工间歇、coffee table 茶几、
coffee morning 是英式的募款茶会。习语 wake up and
smell the coffee 是清醒点、看清现实。
① She grinds her own coffee and will not touch anything from a jar.
= 她自己磨咖啡，罐装的碰都不碰。
coffee = 咖啡
② Two coffees, please, and whatever is left in the cabinet.
= 请来两杯咖啡，柜子里剩什么都拿来。
a coffee = 一杯咖啡
③ We took a coffee break that ran for the better part of an hour.
= 我们歇了个咖啡时间，歇了差不多一个钟头。
a coffee break = 工间歇
④ Put it on the coffee table, on top of the pile that never moves.
= 放在茶几上，就搁在那摞从没挪过的东西上面。
a coffee table = 茶几
⑤ Wake up and smell the coffee; they have been planning this since March.
= 清醒点吧，他们从三月就在谋划这件事了。
wake up and smell the coffee = 认清现实
⑥ The church held a coffee morning and raised enough to fix the roof.
= 教堂办了场咖啡义卖早会，筹到的钱够修屋顶。
a coffee morning = 募款茶会（英式）
这是英式的一种小型慈善活动：上午聚在一起喝咖啡、顺便募捐。
⑦ She ordered a white coffee and got something with cream on top.
= 她要了杯加奶咖啡，端上来的却顶着一层鲜奶油。
a white coffee = 加奶咖啡（英式）
⑧ They met in a coffee house near the docks that has since burned down.
= 他们在码头附近一家咖啡馆碰面，那馆子后来烧掉了。
a coffee house = 咖啡馆（旧式、偏文雅）；a coffee shop = 咖啡店（日常说法）
指同一类地方，coffee house 带旧时文人聚谈的味道，今天日常都说 coffee shop。
⑨ The office got a new coffee machine and nobody has worked out the buttons.
= 办公室来了台新咖啡机，按钮谁都没弄明白。
a coffee machine = 咖啡机（英式常用）；a coffee maker = 咖啡机（美式常用）
同一样东西两个说法，英美各偏一个，不必细分。
⑩ She baked a coffee cake for the meeting and took most of it home.
= 她为开会烤了个咖啡蛋糕，大半又带回了家。
a coffee cake = 咖啡味蛋糕（英式）；配咖啡吃的甜点（美式）
同一个词两边指的东西不一样：英式是蛋糕本身有咖啡味，美式是佐咖啡的点心。
⑪ A spoonful of coffee essence goes into the icing at the very end.
= 最后往糖霜里加一勺咖啡香精。
coffee essence = 咖啡浓缩液（烘焙调味用）
瓶装的浓缩糖浆，做点心时用来上味，不是拿来冲着喝的。
⑫ The neighbours hold a coffee klatch every Tuesday and discuss everyone else.
= 邻居们每周二聚在一起喝咖啡聊天，把别人都议论一遍。
a coffee klatch = 边喝咖啡边闲聊的小聚（美式）
从德语借来的词，后半截那个成分是「闲话」；也拼作 coffee klatsch。
⑬ It ended up as a coffee-table book that nobody has opened twice.
= 它最终成了本装点客厅的画册，没人翻过第二遍。
a coffee-table book = 图多字少、供人随手翻的大开本画册
带一点贬义：暗示是拿来摆的，不是拿来读的。
构词：阿拉伯语 qahwa，经土耳其语进欧洲各语
注意用法：说一杯时可数。

coffer
核心：两支。一是钱箱与库藏：多用复数指一个机构的资金，
the public coffers 是公共财库，这一支最常读到。二是
建筑上的方格镶板，coffered ceiling 是格镶天花。可数。
① The public coffers are empty and the road work stops in April.
= 公共财库空了，道路工程四月停工。
the coffers = 库藏、资金
② The tax filled the coffers for exactly two years.
= 那项税让财库充实了整整两年。
fill the coffers = 让库藏充实
③ The hall has a coffered ceiling with a rose in every panel.
= 那个厅是格镶天花，每一格里雕一朵花。
coffered = 带方格镶板的
构词：希腊语 kophinos 篮子
注意用法：说资金那一支最常读到。

coffin
核心：棺材：装遗体下葬或火化的那口箱。习语 a nail in
the coffin 是又添一道致命打击，很常读到。美式也说
casket。可数。
① The coffin was made to measure and still would not go round the corner.
= 那口棺材是量着做的，转角处还是过不去。
a coffin = 棺材
② That was another nail in the coffin of the branch line.
= 那对那条支线来说又是一道致命打击。
a nail in the coffin = 一道致命打击
构词：希腊语 kophinos 篮子
注意用法：那个习语很常读到。

cog
核心：齿轮上的齿，也直接指小齿轮。习语最常读到的是
a cog in the machine：说人只是庞大机器里一个无关紧要的
小齿轮。cogwheel 是齿轮。可数。
① A cog had sheared off and jammed the whole line for a shift.
= 一个齿被剪断，卡得整条线停了一个班。
a cog = 齿轮上的齿
② He felt like a cog in the machine until the day they asked his opinion.
= 直到有天他们问起他的看法，他一直觉得自己只是机器里的一个小齿轮。
a cog in the machine = 大机构里无关紧要的一员
③ The cogwheel drives the drum through a chain you can see turning.
= 那个齿轮经一条看得见转的链子带动滚筒。
a cogwheel = 齿轮
构词：中古英语 cogge
注意用法：那个习语比字面义常读到。

cogent
核心：论证有力、说得让人不能不服：说理由、论点与说法，
褒义，书面语。名词 cogency，副词 cogently。
① She made a cogent case in nine minutes and sat down.
= 她九分钟里论证得很有力，说完就坐下了。
a cogent case = 有力的论证
② The argument lacks cogency and rests on one unnamed source.
= 那个论点没有说服力，全靠一个没具名的来源。
cogency = 说服力
③ He argued cogently for reform and lost the vote anyway.
= 他为改革说得很有力，表决还是输了。
cogently = 有说服力地
构词：拉丁语 cogere 驱使、迫使
注意语域：书面，褒义。

cogitate
核心：细想、琢磨：正式或半开玩笑地说在思考，cogitate on
something 是琢磨某件事。名词 cogitation。今天多带一点
戏谑。
① He sat cogitating on the problem and ate his way through a packet of biscuits.
= 他坐着琢磨那个问题，一包饼干吃了个精光。
cogitate on = 琢磨某事
② After much cogitation she agreed, and regretted it by Tuesday.
= 想了很久她答应了，到周二就后悔了。
cogitation = 思索
构词：拉丁语 cogitare 思考
注意语域：正式，或半开玩笑。
