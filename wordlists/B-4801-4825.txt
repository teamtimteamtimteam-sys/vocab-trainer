cocksucker
核心：极粗俗的侮辱语，美式常用，字面猥亵，实际是骂人
话里最重的那一类。任何正式场合与书面写作都不能用；收在
这里只为读到能认得。可数。
① He called the referee a cocksucker.
= 他用最难听的脏话骂了裁判。
a cocksucker = 极粗俗的骂人话
② Subtitles usually soften cocksucker into something milder.
= 字幕一般把这个词弱化成温和些的说法。
soften into = 弱化成
构词：由两个粗俗成分拼成
注意语域：极粗俗，只需认得，绝不要用。

cocksure
核心：过分自信、有把握得让人反感：带明显的贬义，多说
年轻人或说话的口气。名词 cocksureness。
① He is cocksure about everything.
= 他什么事都一副十拿九稳的样子。
cocksure = 过分自信的
② A cocksure tone put them off.
= 那种自负的口气让人反感。
put somebody off = 让人反感
③ Confidence is fine; cocksureness is not.
= 自信没问题，自负不行。
cocksureness = 过分自信
构词：由表示公鸡与确定的两部分拼成
注意别混：confident 是褒义，这个一定带批评。

cocktail
核心：三支。一是鸡尾酒。二是引申的混合体：a cocktail of
drugs 是几种药混着用，多带负面意味。三是作定语说社交
场合：a cocktail party 是鸡尾酒会。可数。
① She ordered a cocktail.
= 她点了杯鸡尾酒。
a cocktail = 鸡尾酒
② He was on a cocktail of drugs.
= 他同时用着几种药。
a cocktail of = 几样混在一起的……
③ They went to a cocktail party.
= 他们去了个鸡尾酒会。
a cocktail party = 鸡尾酒会
④ She wore a cocktail dress.
= 她穿了件小礼服。
a cocktail dress = 及膝小礼服
⑤ Spear the olives with a cocktail stick.
= 用鸡尾酒签把橄榄串起来。
a cocktail stick = 鸡尾酒签（插小食的木签）
英式说法，美式多把同一样东西叫 toothpick。
⑥ The cocktail waitress took our order.
= 端酒的女服务员来点单。
a cocktail waitress = 酒吧、赌场里端酒的女服务员（美式）
带性别的旧称，今天的招聘与报道多改说 server 以避性别指称。
构词：来历有几种说法，十九世纪美式英语
注意用法：混合体那一支多带负面意味。

cocky
核心：自以为了不起、张扬：带贬义但语气比 cocksure 轻，
常说年轻人。名词 cockiness。口语。
① Don't get cocky.
= 别太张扬。
cocky = 自以为了不起的
② One win made him cocky.
= 赢了一场他就狂了。
make somebody cocky = 让某人张扬起来
③ His cockiness annoyed the team.
= 他那份张扬让队里不快。
cockiness = 自负张扬
构词：由表示公鸡的那个词加形容词后缀
注意语域：口语，带贬但语气不重。

cocoa
核心：两支。一是可可粉：烘焙磨过的可可豆粉。二是用它冲
的热饮，英式家常说法。不可数。
① Stir the cocoa into the milk.
= 可可粉拌进牛奶。
cocoa = 可可粉
② She made a mug of cocoa.
= 她冲了一杯可可。
a mug of cocoa = 一杯可可饮
③ The recipe needs cocoa powder.
= 那个配方要用可可粉。
cocoa powder = 可可粉
④ The cream contains cocoa butter.
= 那款面霜含可可脂。
cocoa butter = 可可脂
名字里的 butter 跟乳制品无关，指的是可可豆里榨出的那层油脂。
构词：由 cacao 那个词讹变而来
注意别混：cacao 是树与生豆，这个是加工后的粉与饮料。

coconut
核心：椰子：热带棕榈的果实，外壳硬、里面是白肉与椰汁。
coconut milk 是椰奶，coconut water 是椰子水。
① Crack the coconut open.
= 把椰子敲开。
a coconut = 椰子
② The curry uses coconut milk.
= 那道咖喱用椰奶。
coconut milk = 椰奶
③ Coconut water is sold everywhere.
= 椰子水到处都有卖。
coconut water = 椰子水
④ The hallway was covered with coconut matting.
= 门厅里铺着椰棕地垫。
coconut matting = 椰棕地垫
matting 指成片铺开的垫料，跟单块的 mat 分开说。
⑤ She spread coconut butter on the toast.
= 她在吐司上抹了椰子酱。
coconut butter = 椰子酱（连肉带油磨成的糊）
跟 coconut oil 分开：oil 是榨出来的油，butter 是整颗椰肉磨成的。
⑥ He won a goldfish at the coconut shy.
= 他在椰子投掷摊赢了条金鱼。
a coconut shy = 游园会里的椰子投掷摊
英式游园会的老游戏，拿球把架上的椰子砸下来；这里的 shy 是「投掷」的旧义。
构词：葡萄牙语 coco 鬼脸，因壳上三个凹点像脸
注意别混：椰奶是压出来的，椰子水是里面本来的汁。

cocoon
核心：两支。一是茧：蛾的幼虫吐丝结成的那层壳。二是引申
的护得严实的小环境，动词是把……裹住护住；名词
cocooning 是宁可待在家里不出门的那种生活取向。可数。
① The larva spins a cocoon.
= 幼虫结出一个茧。
a cocoon = 茧
② She sat in a cocoon of blankets.
= 她裹在一堆毯子里。
a cocoon of = 裹得严实的一层……
③ They cocooned the child from bad news.
= 他们把坏消息隔着不让孩子知道。
cocoon somebody from = 把某人与……隔开护住
④ Cocooning became a trend that winter.
= 那个冬天窝家成了风气。
cocooning = 宁可待在家里的生活取向
构词：法语 cocon 茧
注意别混：蝶多是裸蛹，蛾才结茧。

cod
核心：鳕鱼：北大西洋的大型食用鱼，英国炸鱼薯条里最常用。
单复数同形。cod liver oil 是鱼肝油。英式口语里它还作
定语表示假的、装出来的。
① They landed two hundred cod.
= 他们捕了两百条鳕鱼。
cod = 鳕鱼
旧文与商业里也说 codfish，指的是同一种鱼。
codfish = 鳕鱼（较旧的说法）
② Cod stocks fell sharply.
= 鳕鱼资源大幅下降。
stocks = 资源存量
③ She took cod liver oil daily.
= 她每天吃鱼肝油。
cod liver oil = 鱼肝油
④ He put on a cod French accent.
= 他装了个假法国口音。
cod = 假的、装出来的（英式口语）
构词：来历不确定，中古英语已有
注意用法：单复数同形。

coda
核心：两支。一是乐曲的尾声：正文结束后加的那一段收尾。
二是引申指一件事或一本书的收尾部分，这一支在书评里常
读到。可数。
① The coda repeats the theme.
= 尾声把主题再奏一遍。
a coda = 乐曲尾声
② The last chapter is a coda.
= 最后一章是个收尾。
a coda = 收尾部分
③ The trip was a coda to the year.
= 那趟旅行是那一年的收尾。
a coda to = ……的收尾
构词：意大利语 coda 尾巴
注意用法：引申义在书评里常读到。

coddle
核心：两支。一是过分呵护：把人照顾得太周到，多带批评。
二是烹饪上的小火慢煮：coddled eggs 是嫩煮蛋。
① They coddle their students.
= 他们把学生护得太过。
coddle = 过分呵护
② He was coddled as a boy.
= 他小时候被宠得厉害。
be coddled = 被过分呵护
③ Coddled eggs are cooked gently.
= 嫩煮蛋是小火慢煮的。
coddled = 小火慢煮的
构词：可能与表示热饮的旧词 caudle 有关
注意语域：呵护那一支多带批评。

code
核心：五支。一是代码：编程写的指令，动词是编程，coded
是编了码的。二是密码。三是号码式的编码：a postal code
是邮政编码。四是规范与准则：a code of conduct 是行为
准则。五是暗语：speak in code 是话里有话。可数。
① She writes code all day and has not read a novel since university.
= 她整天写代码，大学以后没读过一本小说。
write code = 写代码
② The message was in code and took the whole department a week to read.
= 那条消息是加密的，整个部门读了一周。
in code = 以密码形式
③ Enter the postal code and the rest of the address fills itself in.
= 输入邮政编码，地址其余部分会自动填好。
a postal code = 邮政编码
④ The firm has a code of conduct that nobody has been asked to read.
= 公司有行为准则，却没人被要求读过。
a code of conduct = 行为准则
⑤ He was speaking in code and half the room understood him perfectly.
= 他说的是隐语，屋里一半人完全听得懂。
speak in code = 说得含蓄有暗指
⑥ The data is coded by region and the codes were changed without notice.
= 数据按地区编码，而编码不打招呼就改了。
coded = 编了码的
⑦ The operation had the code name Overlord and was known to far too many.
= 这次行动代号「霸王」，知情的人多得离谱。
a code name = 代号；code-named = 代号为……的
军事与警方用语；形容词形式常见于报道，如 a code-named operation。
⑧ Snowdrop was the code word for the retreat and was never used.
= 「雪花莲」是撤退的暗号，一次也没用上。
a code word = 暗号；也指政治上讳饰的说法
第二义常见于评论：说某个词是 a code word for something，意思是拿它当幌子。
⑨ The industry has a code of practice on advertising and breaks it weekly.
= 这个行业有广告业务守则，每周都违反一次。
a code of practice = 业务守则
比法律松、比惯例紧：行业自订，成员自愿遵守，违反了多半没有法律后果。
⑩ The two airlines have a code-sharing agreement and blame each other for delays.
= 两家航空公司有代码共享协议，误点时互相推诿。
code-sharing = 代码共享（一个航班挂两家公司的班号）
航空业术语；订票时看到两个班号指同一架飞机，就是这回事。
⑪ Bilingual speakers do a lot of code-switching without noticing they do it.
= 双语者常常语码转换，自己却没察觉。
code-switching = 语码转换（说话中途换语言或语体）
语言学术语。这里的 code 指一套语言或语体，不是密码那个义。
⑫ The files are color coded by year and the yellow ones are missing.
= 文件按年份用颜色编码，黄色那批不见了。
color code = 用颜色分类标记（美式拼法）
名词说 a color code，动词直接用它，过去分词 color-coded。
构词：拉丁语 codex 木简、法典
注意用法：代码与准则两支在今天的文字里最常读到。

codeine
核心：一种鸦片类止痛药，也用来止咳，常与别的药配成
复方。有依赖性，多数国家管制。不可数。
① The tablets contain codeine.
= 那些药片含可待因。
codeine = 可待因
② Codeine can be habit-forming.
= 可待因会形成依赖。
habit-forming = 会形成依赖的
构词：希腊语 kodeia 罂粟头
注意用法：医药与管制报道里常见。

codependency
核心：共依存：一段关系里两个人互相强化对方的问题行为，
最常说酒瘾、药瘾家庭里那种彼此拖住的模式。形容词与名词
都是 codependent。心理学与自助书里的词。不可数。
① The therapist named it codependency.
= 治疗师把那称作共依存。
codependency = 共依存
② They fell into a codependent pattern.
= 他们陷进了互相拖住的模式。
codependent = 共依存的
③ Codependents often deny the problem.
= 处在这种关系里的人常否认有问题。
a codependent = 处在共依存关系里的人
构词：由表示共同与依赖的两部分拼成
注意用法：心理学与自助书里的词。

codex
核心：手抄本：古代与中世纪装订成册的抄写文献，跟卷轴
相对。复数 codices。文献学与历史里的词。可数。
① The codex dates from the fourth century.
= 那部抄本是四世纪的。
a codex = 手抄本
② Codices replaced scrolls.
= 抄本取代了卷轴。
a scroll = 卷轴
③ The library holds three codices.
= 那家图书馆藏了三部抄本。
hold = 收藏
构词：拉丁语 codex 木简、书册
注意用法：复数是 codices。

codger
核心：老家伙：说上了年纪的男人，多说 an old codger，
带一点无奈的调笑，不算恶意但也不客气。英式偏多，
带旧气。可数。
① He is a cheerful old codger.
= 他是个挺乐呵的老家伙。
an old codger = 老家伙（调笑）
② Codgers gathered in the corner.
= 几个老头聚在角落。
gather = 聚集
构词：可能出自旧词 cadger
注意语域：调笑口气，正式场合不用。

codicil
核心：遗嘱附件：在原遗嘱之外另立的一份补充或修改文件，
跟原件一起生效。法律用词。可数。
① She added a codicil in March.
= 她三月加了一份遗嘱附件。
a codicil = 遗嘱附件
② The codicil changed one bequest.

③ Codicils must be witnessed too.
= 附件也要有见证。
be witnessed = 有见证人
构词：拉丁语 codicillus 小文书
注意用法：法律文书里的词。

codify
核心：把散着的规则整理成成文的一套：codify the law 是
把法律法典化，也说把惯例写成明文。名词 codification。
书面与法律用词。
① They codified the common law.
= 他们把普通法法典化了。
codify = 编成法典、整理成明文
② Custom was later codified.
= 那些惯例后来被写成明文。
be codified = 被写成成文规则
③ Codification took ten years.
= 法典化用了十年。
codification = 法典化
构词：由表示法典的那个词加表示使的词根
注意语域：书面与法律用词。

codpiece

codswallop
核心：英式口语：胡说八道、废话，多说 a load of

coed

今天被视为过时且带轻慢，避开。也拼 co-ed。

coefficient

coelacanth
