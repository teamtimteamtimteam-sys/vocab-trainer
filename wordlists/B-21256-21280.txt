size

核心：名词：大小、尺寸（不可数或可数）：the size of something；（衣服、鞋的）尺码、号（可数）：What size are you?；规模、数量。动词，及物：按大小分类；定尺寸。习语：cut somebody down to size 是挫某人的锐气；try something for size 是试试看合不合适。

= 我和我哥哥身材一样，所以常常换着穿衣服。

= 我们对那座房子的大小感到吃惊，它有十二间卧室。

= 教练打量了一下那个新球员，决定让他进队。

⑤ The champion was cut down to size when a young player beat him in the first round.
= 那位冠军首轮就输给了一个年轻选手，锐气大挫。
cut somebody down to size = 挫某人的锐气
⑥ The shop assistant told him to try the jacket for size, because she thought it would fit.
= 店员叫他试试那件夹克合不合身，她觉得他穿正合适。
try something for size = 试试合不合适
⑦ Doctors are worried that size zero models are a bad example for young girls.
= 医生们担心零码模特给小女孩们树立了坏榜样。
size zero = 零码（极瘦）
