alpaca
核心：南美安第斯山区驯养的一种骆驼科动物，比羊驼亲戚 llama 小，
专为剪毛而养。毛细软保暖，也用这个词指毛料本身和织成的衣物。
① They keep a herd of alpacas.
= 他们养了一群羊驼。
a herd of alpacas = 一群羊驼
② The scarf is pure alpaca.
= 那条围巾是纯羊驼毛的。
pure alpaca = 纯羊驼毛
③ Alpaca is warmer than sheep's wool.
= 羊驼毛比绵羊毛更保暖。
注意用法：
既指动物，也指毛料。
近义对照：
alpaca = 羊驼（体小，取毛）
llama = 大羊驼（体大，驮货）

alpenhorn
核心：阿尔卑斯山区牧人用的"阿尔卑斯长号"——一根三四米长的木管，
末端向上翘，声音低沉能传很远，从前用来在山谷之间传话和唤牛。
也拼作 alphorn。
① He blew the alpenhorn at dawn.
= 他在拂晓吹响了阿尔卑斯长号。
blow the alpenhorn = 吹阿尔卑斯长号
② The alpenhorn can be four metres long.
= 阿尔卑斯长号能有四米长。
③ Alpenhorns carry sound across valleys.
= 阿尔卑斯长号的声音能穿过山谷。
注意拼写：
alpenhorn = 阿尔卑斯长号
alphorn = 阿尔卑斯长号（较短的拼法）
注意语域：
乐器名称，瑞士与奥地利民俗。

alpha
核心：希腊字母表的第一个字母，引申出好几层用法：统计学里的
显著性水平，动物行为学里的"头领"，科技行业里的"内测版本"。
固定说法 alpha and omega 指"始与终"。
① Alpha is the first Greek letter.
= 那是希腊字母表的头一个字母。
② The wolf pack has an alpha male.
= 狼群里有一只头狼。
alpha male = 头领雄性、强势男性
③ The software is still in alpha.
= 那个软件还在内测阶段。
alpha version = 内测版本
alpha test = 内部测试
④ Alpha particles are stopped by paper.
= 阿尔法粒子一张纸就能挡住。
alpha particle = 阿尔法粒子
alpha radiation = 阿尔法辐射
⑤ He is the office alpha geek.
= 他是办公室里的头号技术宅。
alpha geek = 团队里技术最强的人
⑥ She set alpha at zero point zero five.
= 她把显著性水平定在百分之五。
注意用法：
作词头时后面接名词，构成一族说法。

alphabet
核心：指一套字母的全体，是集合概念，所以说 the English alphabet
而不说 26 alphabets——单个字母叫 letter，这是高频错误。
① The English alphabet has 26 letters.
= 英语字母表有二十六个字母。
单个字母是 letter，不是 alphabet。
② Learn the Greek alphabet.
= 学希腊字母表。
③ Files are in alphabetical order.
= 文件按字母顺序排列。
alphabetical order = 字母顺序
词族：
alphabetical = 按字母顺序的
alphabetically = 按字母顺序地
④ The soup is alphabetic chaos.
= 那锅汤字母乱成一团。
alphabetic = 字母的、按字母顺序的
⑤ Please alphabetize the list.
= 请把名单按字母顺序排好。
alphabetize = 按字母顺序排列
⑥ The kids ate alphabet soup.
= 孩子们吃的是字母汤。
alphabet soup = 字母汤；一堆看不懂的缩写

alphabetical
核心：指"按字母顺序的"。最高频的搭配是
in alphabetical order。
① Names are in alphabetical order.
= 名字按字母顺序排列。
in alphabetical order = 按字母顺序
② Make an alphabetical list.
= 做一份按字母排的清单。
alphabetical list = 字母序清单
③ The index is alphabetical.
= 那个索引按字母排。
词族：
alphabet = 字母表
alphabetically = 按字母顺序地
近义对照：
alphabetical = 按字母序
chronological = 按时间序
numerical = 按数字序

alphabetically
核心：副词，"按字母顺序地"。常修饰 arrange、list、
sort、order 这类动词。
① Files are arranged alphabetically.
= 文件按字母顺序排列。
arrange alphabetically = 按字母排序
② Sort the names alphabetically.
= 把名字按字母排好。
sort alphabetically = 按字母排序
③ Entries appear alphabetically.
= 词条按字母顺序排列。
词族：
alphabet = 字母表
alphabetical = 字母序的

alphanumeric
核心：形容词，指"字母数字混合的"——只由字母和数字组成，有时也算上
少量符号。多用来说密码、编号和输入框的格式要求。
① The password must be alphanumeric.
= 密码必须是字母数字混合的。
must be alphanumeric = 必须字母数字混合
② Each part has an alphanumeric code.
= 每个零件都有字母数字编码。
alphanumeric code = 字母数字编码
③ The keypad accepts alphanumeric input.
= 那个键盘接受字母数字输入。
alphanumeric input = 字母数字输入
注意语域：
计算机与信息管理用语。

alphorn
核心：alpenhorn 的另一种拼法，指的是同一样东西——阿尔卑斯山区
那根三四米长、末端上翘的木制长号。两种拼法都通行。
① The alphorn is a Swiss emblem.
= 阿尔卑斯长号是瑞士的象征之一。
a Swiss emblem = 瑞士的象征
② Players line up with their alphorns.
= 吹奏者举着长号排成一排。
③ An alphorn has no valves or keys.
= 阿尔卑斯长号没有活塞也没有按键。
no valves or keys = 无活塞无按键
注意拼写：
alphorn = 阿尔卑斯长号（短拼法）
alpenhorn = 阿尔卑斯长号（长拼法）
注意语域：
乐器名称，瑞士民俗音乐。

alpine
核心：指"高山的、高海拔的"，也特指阿尔卑斯山区的。
大写 Alpine 时专指阿尔卑斯。
① Alpine plants survive cold.
= 高山植物耐寒。
alpine plant = 高山植物
② They went alpine skiing.
= 他们去滑高山滑雪。
alpine skiing = 高山滑雪
③ The village has an alpine setting.
= 那个村子坐落在高山环境中。
词源：Alps 阿尔卑斯山
近义对照：
alpine = 高山的（海拔高）
mountainous = 多山的（地形）
highland = 高地的（地区）

alpinism
核心：指"登山运动"，尤其是攀登阿尔卑斯式的高山峻岭，讲究轻装
快速、不依赖固定营地。做这件事的人叫 alpinist。
① Alpinism demands endurance and nerve.
= 登山运动既要耐力也要胆量。
demand endurance = 需要耐力
② He took up alpinism in his twenties.
= 他二十几岁开始登山。
take up alpinism = 开始登山运动
③ The alpinist soloed the north face.
= 那位登山家单人攀上了北壁。
alpinist = 登山家
④ Alpinists prefer light, fast ascents.
= 登山家偏好轻装快攀。
注意语域：
登山运动用语，带专业色彩。
近义对照：
alpinism = 阿尔卑斯式登山（轻装快攀）
mountaineering = 登山（通称）

already
核心：表示"比预期早、已经发生了"。通常用于肯定句和完成时；放在
疑问句里表示惊讶（"这么快就…？"）。和 yet、still 的分工要分清。
① I've already eaten.
= 我已经吃过了。
② She was already there.
= 她已经在那儿了。
常用搭配：
already known = 已知的
not… already? = 这么快就…？
③ Are you leaving already?
= 你这就要走了？
用在疑问句里表示意外。
④ It's already too late.
= 已经太晚了。
常用搭配：
already in place = 已经就位
as already noted = 如前所述
注意区别：
already 已经（肯定句）
yet 还没、了吗（否定和疑问句）
still 仍然（动作在持续）

alright
核心：all right 的合写形式，口语和非正式书面里常见，
但正式文体和多数编辑规范仍要求写成 all right。
① Is everything alright?
= 一切还好吗？
② That's alright with me.
= 我没意见。
alright with someone = 某人可以接受
③ He said it was alright.
= 他说没问题。
注意拼写：
非正式场合 alright 可用，
正式写作一律用 all right。
近义对照：
alright / all right = 没事、还行
OK = 好（最口语）

Alsatian
核心：两层意思。一是"德国牧羊犬"的英式旧称——一战后英国人不愿用
带德国字样的名字，就改用这个；二是指法国阿尔萨斯地区的人、事物
和那里出的白葡萄酒。
① The police use Alsatians.
= 警方用德国牧羊犬。
② An Alsatian guarded the yard.
= 一条德国牧羊犬看着院子。
③ They ordered a bottle of Alsatian white.
= 他们点了一瓶阿尔萨斯白葡萄酒。
Alsatian white = 阿尔萨斯白葡萄酒
注意地域：
犬种义是英式旧称，今天多说 German shepherd。
近义对照：
Alsatian = 德国牧羊犬（英式旧称）
German shepherd = 德国牧羊犬（通用名）

also
核心：表示"也"，位置在实义动词前、be 动词后、助动词后。不能放句
末——放句末要用 too 或 as well。这是中国学生高频错误。
① She also speaks French.
= 她还会说法语。
放在实义动词前。
② He is also a doctor.
= 他也是医生。
放在 be 动词后。
③ I have also finished.
= 我也做完了。
放在助动词后。
④ Not only is it cheap, it's also good.
= 它不但便宜，还好用。
not only… but also = 不但…而且
近义对照：
also = 也（句中）
too = 也（句末，口语）
as well = 也（句末，稍正式）
注意区别：
also 不能放句末
too / as well 放句末
不说 She speaks French also.
⑤ He ended up an also-ran.
= 他最后成了个陪跑的。
also-ran = 陪跑者、落选者

on its own = 单独地

注意写法：
键名首字母大写。
注意语域：
计算机操作用语。

alt-right

altcoin

altcoin = 另类币（比特币之外的）

alter
核心：指做局部改动而不换掉整体，衣服改尺寸、计划改细节都用它。
和 change 的关键差别：change 可以是整个换掉，alter 只是改一改。
① I need to alter this dress.
= 我得改一下这条裙子。
② Nothing has altered.
= 什么都没变。
③ The plan was slightly altered.
= 那个计划稍作了修改。
常用搭配：
alter course = 改变航向
alter beyond recognition = 改得认不出
词族：
alteration = 改动
unaltered = 未经改动的
注意区别：
alter 局部修改（原物还在）
change 改变、更换（可能换掉）
注意别混：alter 修改 / altar 祭坛
④ Online he adopts an alter ego.
= 在网上他有另一个身份。
alter ego = 第二自我、另一个身份
⑤ The contract is not alterable.
= 那份合同不可更改。
alterable = 可更改的
⑥ The alternation of wet and dry seasons shapes the land.
= 干湿季交替塑造了这片土地。
alternation = 交替、轮换

alteration
核心：指"改动、修改"，尤指局部的。服装店的 alterations
特指改衣服尺寸。
① We made a few alterations.
= 我们做了几处改动。
make an alteration = 做出改动
② The shop does alterations.

do alterations = 提供修改服务

alter = 改变

altercation

a heated altercation = 激烈口角
② An altercation broke out.

break out = 爆发
③ Police were called to an altercation.

注意发音：/ˌɔːltəˈkeɪʃn/
近义对照：
altercation = 口角（正式，激烈）
argument = 争论（通用）
quarrel = 争吵（较私人）
brawl = 打架（动手）

alternate
核心：动词是"交替进行"，形容词有两个意思："轮流的"，
以及美式里等于 alternative（替代的）。动词形容词重音不同。
① Wet days alternated with dry ones.
= 雨天和晴天交替出现。
alternate with = 与…交替
② He works on alternate days.
= 他隔天上一次班。
alternate days = 隔日
③ Take an alternate route.
= 走另一条路。
美式用法，等于 alternative
注意发音：
动词 /ˈɔːltəneɪt/ 形容词 /ɔːlˈtɜːnət/
注意区别：
英式 alternate = 交替的
美式 alternate 还可作"替代的"
④ Alternate angles are equal.
= 内错角相等。
alternate angles = 内错角（几何）

alternately
核心：副词，"轮流地、交替地"。注意和 alternatively
（或者、要不然）意思完全不同，混用是高频错误。
① She alternately laughed and cried.
= 她一会儿笑一会儿哭。
alternately A and B = 时而 A 时而 B
② Stripes appear alternately.
= 条纹交替出现。
③ Apply heat and cold alternately.
= 冷热交替敷。
注意区别：
alternately = 交替地（轮流发生）
alternatively = 或者（提出另一选项）
这两个词混用很常见，务必分清。

alternating current
核心：物理与电工术语，指"交流电"——电流方向周期性来回改变，
每秒变向的次数就是频率。家用电网送的就是交流电，因为它便于
变压远距离输送。常缩写。
① Homes are supplied with alternating current.
= 住宅用的是交流电。
supplied with = 供以…
② Alternating current changes direction fifty times a second.
= 交流电每秒变向五十次。
change direction = 改变方向
③ Transformers only work with alternating current.
= 变压器只对交流电起作用。
注意语域：
物理与电气工程术语。
注意别混：
alternating current = 交流电（方向来回变）
direct current = 直流电（方向不变）

alternative
核心：底层是"另一个可以选的"。名词是"可选项"，形容词一是"替代的"，
二是"另类的、非主流的"。严格说 alternative 只用于两者之间，
但现代英语已放宽。
① Is there an alternative?
= 还有别的办法吗？
② We have no alternative but to wait.
= 我们除了等别无选择。
have no alternative but to = 只能
③ They use alternative energy.
= 他们用替代能源。
④ He likes alternative music.
= 他喜欢另类音乐。
这里：
alternative = 非主流的
副词形式：
alternatively = 或者、要不然
⑤ The bus runs on alternative fuel.
= 那辆公交烧的是替代燃料。
alternative fuel = 替代燃料
⑥ She turned to alternative medicine.
= 她转而求助替代医学。
alternative medicine = 替代医学
⑦ They debated the alternative vote.
= 他们辩论了排序复选制。
alternative vote = 排序复选制（选举）
