⑤ The new session of parliament opens in October with a speech by the king.
= 议会的新会期十月开幕，由国王发表讲话。
a session of parliament = 议会会期

set
/set/
核心：动词（set, set）：放、摆：set something on the table、set the table；设定、调定：set the alarm、set the clock；定下（日期、价格、规则）：set a date、set a price；树立、创下：set an example、set a record；布置（作业、任务）：set homework；使处于某种状态：set somebody free、set fire to something；（太阳）落下；（液体）凝固；（骨头）接好。名词，可数：一套、一副：a set of；（电视）机：a television set；（电影、戏剧的）布景、片场；（网球等的）一盘。形容词：固定的、规定的：a set menu、a set time；准备好的：be all set；坚决的（反对）。
① She set the vase of flowers on the table by the window.
= 她把那瓶花放在窗边的桌子上。
set something on the table = 把某物放在桌上
② Can you set the table, please? Dinner will be ready in five minutes.
= 你能摆一下餐具吗？晚饭五分钟就好。
set the table = 摆餐具
英式也说 lay the table。
③ I set the alarm for six o'clock because my train leaves at seven.
= 我把闹钟定在六点，因为我的火车七点开。
set = 设定
set the alarm = 定闹钟
④ They have not set a date for the wedding yet, but it will probably be next summer.
= 他们还没定婚期，不过很可能是明年夏天。
set a date = 定日期
⑤ Parents should set a good example by putting their phones away at dinner.
= 父母应该以身作则，吃饭时把手机收起来。
set an example = 树立榜样
反面是 set a bad example（带坏头）。
⑥ She set a new world record in the hundred metres at the age of nineteen.
= 她十九岁时创造了百米新的世界纪录。
set a record = 创纪录
⑦ The children opened the cage and set the bird free in the garden.
= 孩子们打开笼子，在花园里把那只鸟放了。
set somebody free = 释放某人
⑧ The angry crowd set fire to two cars outside the football ground.
= 愤怒的人群在足球场外放火烧了两辆车。
set fire to something = 放火烧某物
别和 catch fire（着火）混：set fire to 是有人故意点的。
⑨ We sat on the beach and watched the sun set behind the islands.
= 我们坐在海滩上，看着太阳落到群岛后面。
the sun sets = 太阳落下
⑩ Put the jelly in the fridge for three hours until it has set.
= 把果冻放进冰箱三个小时，直到凝固。
set = 凝固
⑪ The teacher set us twenty questions for homework, and they took all evening.
= 老师给我们布置了二十道作业题，做了一整个晚上。
set homework = 布置作业
⑫ My grandmother gave us a beautiful set of glasses as a wedding present.
= 奶奶送了我们一套漂亮的玻璃杯当结婚礼物。
a set of = 一套
后面接复数名词，主语是 a set 时动词用单数：A set of keys was found.
⑬ We bought a new television set because the old one kept losing the picture.
= 我们买了一台新电视机，因为旧的老是没图像。
a television set = 电视机
⑭ The famous actor was very friendly to everyone on the film set.
= 那位著名演员对片场里的每个人都很友好。
a film set = 电影片场
⑮ She lost the first set 6–2 but went on to win the match.
= 她第一盘以二比六输了，但最后赢下了比赛。
a set = （网球）一盘
⑯ He had a set point in the second set, but his opponent saved it with a brilliant shot.
= 第二盘他拿到了盘点，但对手一记妙球挽救了这一分。
a set point = 盘点（再赢一分即拿下这一盘）
⑰ The restaurant does a set menu at lunchtime: three courses for fifteen pounds.
= 那家餐厅午餐有套餐：三道菜十五英镑。
a set menu = 套餐
⑱ "Are you all set for the trip?" "Yes, the bags are in the car."
= "旅行都准备好了吗？""好了，包都在车上。"
be all set = 准备就绪
⑲ My father is set against the idea of me leaving school at sixteen.
= 我父亲坚决反对我十六岁辍学。
be set against something = 坚决反对某事
⑳ As soon as she got home, she set about cleaning the kitchen from top to bottom.
= 她一到家就开始把厨房彻底打扫一遍。
set about doing something = 开始做某事
set about = 着手
㉑ The storm last month set back the building work on the new school by three weeks.
= 上个月那场暴风雨使新学校的建筑工程推迟了三个星期。
set back = 推迟、阻碍
口语里 set somebody back 还能指「花掉某人多少钱」：That coat set me back £200.
㉒ The new law set neighbours against each other, and the village was never the same again.
= 那项新法让邻里反目，村子再也回不到从前了。
set A against B = 使 A 和 B 对立
㉓ Every student has to read the set books for the exam, including two plays by Shakespeare.
= 每个学生都要读考试规定的指定书目，包括莎士比亚的两部剧本。
a set book = 指定书目
㉔ "Once upon a time" is a set phrase that begins many fairy stories.
= "从前"是很多童话故事开头的固定说法。
a set phrase = 固定说法
㉕ The team scored from a set piece, when the tall defender headed in a corner kick.
= 球队通过定位球得分：那个高个子后卫头球攻进了角球。
a set piece = 定位球
㉖ We had to buy a set-top box so that the old television could get the new digital channels.
= 我们得买个机顶盒，旧电视才能收到新的数字频道。
a set-top box = 机顶盒
㉗ My grandfather is very set in his ways and still refuses to use a mobile phone.
= 我祖父的老习惯根深蒂固，至今不肯用手机。
be set in your ways = 积习难改
多用来说上了年纪的人。
㉘ The bus stopped at the corner and set down two old ladies with their shopping bags.
= 公交车在拐角停下，让两位提着购物袋的老太太下了车。
set down = 让（乘客）下车；放下
set down 也指「写下、规定」：The rules are set down in the contract.
㉙ Winter set in early that year, and the lake was frozen by the end of October.
= 那年冬天来得早，十月底湖面就结冰了。
set in = （坏天气、不好的事）开始并持续
主语多是 winter、rain、panic、infection 这类不受欢迎的东西。
㉚ The old stone was set into the wall of the church to remember the men who built it.
= 那块旧石头被嵌进教堂的墙里，纪念建造教堂的人。
set into = 嵌入
㉛ We set off at five in the morning so that we could reach the mountains before lunch.
= 我们早上五点出发，好在午饭前到达山里。
set off = 出发、动身
㉜ Someone opened the back door during the night and set off the burglar alarm.
= 夜里有人打开后门，触发了防盗警报。
set off an alarm = 触发警报
set off 还可指「引爆（炸弹）、引发（一连串事情）」。
㉝ The farmer threatened to set his dogs on anyone who climbed over the fence again.
= 农场主威胁说，谁再翻篱笆就放狗咬谁。
set a dog on somebody = 放狗咬某人
㉞ The explorers set out across the desert with ten camels and enough water for a month.
= 探险队带着十头骆驼和够喝一个月的水，出发穿越沙漠。
set out = 出发、启程
㉟ She set out to prove that a small village school could get better results than the big city schools.
= 她立志要证明，一所村小能比城里的大学校考得更好。
set out to do something = 立志做某事
set out to do 强调一开始就有明确目标。
㊱ My uncle set up his own building company when he was only twenty-five.
= 我叔叔才二十五岁就创办了自己的建筑公司。
set up = 创办、建立
㊲ We set up the tent next to the river before it got dark and started a fire.
= 我们在天黑前在河边搭好帐篷，生起了火。
set up a tent = 搭帐篷
set up 还常指「设圈套陷害」：He says the police set him up.
㊳ On the way home through the forest, the travellers were set upon by a gang of robbers.
= 在穿过森林回家的路上，那些旅人遭到一伙强盗袭击。
be set upon by somebody = 遭到某人袭击
set upon 多用被动，比 attack 更书面。
㊴ He took a set shot from just outside the line, and the ball dropped cleanly through the basket.
= 他在线外一点站定投篮，球干净利落地落进篮筐。
a set shot = （篮球）定点投篮
㊵ For the geometry test you will need a ruler, a protractor and a set square.
= 几何考试你需要带直尺、量角器和三角板。
a set square = 三角板
美式叫 triangle。
㊶ Our set text for the English exam this year is a novel by Jane Austen.
= 我们今年英语考试的指定课文是简·奥斯汀的一部小说。
a set text = 指定课文
㊷ Ever since she visited the hospital as a little girl, she has been set on becoming a doctor.
= 自从小时候去过那家医院，她就一心想当医生。
be set on something = 一心想要某事
和 be set against（坚决反对）正好相反。

setback
/ˈsetbæk/
核心：名词，可数：挫折、障碍、倒退：suffer a setback、a major setback。
① Losing their best player through injury was a serious setback for the team.
= 最好的球员受伤缺阵对球队是个严重挫折。
a setback = 挫折
setback = 障碍
② After a few setbacks at the beginning, the new business started to make money in its second year.
= 开头遇到几次挫折之后，那家新公司第二年开始赚钱了。
suffer a setback = 遭受挫折
