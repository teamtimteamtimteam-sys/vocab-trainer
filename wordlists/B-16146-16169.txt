package
/ˈpækɪdʒ/
核心：名词四支，可数。一是包裹：包好寄出或送来的东西，美式的通行说法，英式多说 parcel；二是（美式）包装盒、包装袋；
三是一揽子（建议、措施、待遇）：a package of measures；四是（计算机）软件包。
动词是包装；也指把…包装、打造成某种形象。名词 packaging 是包装材料、包装方式，不可数。
package holiday、package tour 是（英式）旅行社包办交通食宿的包价旅游；package store 是（美式）只许外卖的酒类专卖店。并入本条。
① A package arrived this morning with no name on the outside.
= 今天早上来了个包裹，外面没写名字。
package = 包裹
a package arrives = 来了个包裹
② Check the date on the package before you open the cheese.
= 打开奶酪之前，看看包装上的日期。
the package = 包装盒
③ The government announced a package of measures to help small farms.
= 政府宣布了一揽子帮助小农场的措施。
a package of measures = 一揽子措施
④ The job comes with a generous package of pay and holidays.
= 那份工作的薪水和假期待遇很优厚。
a pay package = 薪酬待遇
⑤ The goods are packaged in boxes of twelve and sent by lorry.
= 那些货物十二件装一箱，用卡车运走。
be packaged = 被包装
⑥ Half the weight of the parcel was plastic packaging.
= 那个包裹的重量有一半是塑料包装。
packaging = 包装材料
⑦ They booked a package holiday to Spain with flights and meals included.
= 他们订了一趟去西班牙的包价旅游，机票和三餐都含在内。
a package holiday = 包价旅游
a package tour = 包价旅游
⑧ He stopped at the package store on the edge of town for a bottle of whiskey.
= 他在镇边的酒类专卖店停了一下，买了瓶威士忌。
a package store = 酒类专卖店

pad

pad out = 把…凑长

padding = 凑篇幅的废话、衬垫
⑨ In the old film the hero wakes in a padded cell with no memory of his name.
= 那部老片子里，主角在一间软垫隔离室里醒来，不记得自己叫什么。
a padded cell = 软垫隔离室
⑩ We ordered pad thai and a bowl of soup from the stall on the corner.
= 我们在街角的摊子上点了泰式炒河粉和一碗汤。
pad thai = 泰式炒河粉

paddle
/ˈpædəl/

paddleboard（桨板）与 paddleboarding（桨板运动）。
