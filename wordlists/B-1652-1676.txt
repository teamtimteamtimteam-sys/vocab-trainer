atemporal
核心：形容词，指"不受时间限制的、脱离时间脉络的"。哲学和神学里
说某个存在不在时间之内；文学与艺术评论里说一部作品"不带时代印记"，
放在哪个年代看都成立。
① The argument treats God as atemporal.
= 那个论证把神视为超越时间的。
② The novel aims at an atemporal setting.
= 那部小说想营造一个无时代感的场景。
an atemporal setting = 无时代印记的场景
③ Atemporal design ages slowly.
= 不带时代印记的设计不容易过时。
atemporal design = 超越时代的设计
注意语域：
哲学、神学与艺术评论用语。
注意别混：
atemporal = 不在时间之内的
timeless = 永恒的、经久不衰的（更常用）

athwart

= 那条船横在水流上。

② A spar ran athwart the deck.
= 一根圆材横在甲板上。
run athwart = 横贯
③ The ruling ran athwart established practice.
= 那项裁定与惯例相抵触。
run athwart of = 与…相抵触
注意语域：
航海术语与文学用语，日常说 across。
