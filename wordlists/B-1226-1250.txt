aquarium
核心：两条线：家里养鱼的"水族箱"，
和对公众开放的"水族馆"。复数有两种写法。
① He keeps fish in an aquarium.
= 他用水族箱养鱼。
② We visited the aquarium.
= 我们去了水族馆。
③ The aquarium needs cleaning.
= 那个鱼缸该清理了。
注意复数：
aquarium → aquariums 或 aquaria
构词：aqua- 水 + -arium 场所
同类构词：
planetarium 天文馆 / terrarium 生态缸

aquatic
核心：指"水生的、水上的"。既说生物（aquatic plants），
也说运动（aquatic sports）。
① Aquatic plants need light.
= 水生植物需要光照。
aquatic plant = 水生植物
② Swimming is an aquatic sport.
= 游泳是水上运动。
aquatic sport = 水上运动
③ The lake supports aquatic life.
= 那个湖里有水生生物。
aquatic life = 水生生物
反义对照：
aquatic = 水生的
terrestrial = 陆生的
aerial = 空中的

aquavit
核心：指北欧的一种烈酒，用土豆或谷物蒸馏，
以葛缕子等香料调味。不可数。也拼作 akvavit。
① They toasted with aquavit.
= 他们用阿夸维特酒干杯。
toast with = 用…举杯
② Aquavit is flavoured with caraway.
= 阿夸维特以葛缕子调味。
caraway = 葛缕子
③ Aquavit is served chilled.
= 阿夸维特要冰镇着喝。
词源：拉丁语 aqua vitae（生命之水）
同源：
whisky 也源自盖尔语的「生命之水」
eau de vie = 法式白兰地（生命之水）

aqueduct
核心：指跨越山谷输送水的"引水渠、渡槽"，
罗马人修的最著名。可数。
① The Roman aqueduct still stands.
= 那条罗马引水渠还立着。
Roman aqueduct = 罗马渡槽
② The aqueduct crosses the valley.
= 那道渡槽横跨山谷。
③ Aqueducts supplied the city.
= 渡槽为那座城市供水。
构词：aqua 水 + duct 管道
同源：
duct = 管道
conduct = 引导
viaduct = 高架桥（via 路 + duct）

aqueous
核心：化学用语，指"含水的、水状的"。
最常见的搭配是 aqueous solution（水溶液）。
① It's an aqueous solution.
= 那是水溶液。
aqueous solution = 水溶液
② The aqueous phase separated.
= 水相分离了出来。
aqueous phase = 水相
③ Aqueous humour fills the eye.
= 房水充满眼球前部。
aqueous humour = 房水（眼科）
注意发音：/ˈeɪkwiəs/
反义对照：
aqueous = 水性的
oily / organic = 油性的、有机相的

aquifer
核心：地质学词，指能储存和输送地下水的"含水层"。
是地下水资源的核心概念。
① The aquifer supplies drinking water.
= 那个含水层供应饮用水。
② The aquifer is being depleted.
= 那个含水层正在枯竭。
be depleted = 被耗尽
③ Pollution reached the aquifer.
= 污染渗到了含水层。
注意发音：/ˈækwɪfə(r)/
构词：aqui- 水 + -fer 携带
同类构词：
conifer = 针叶树（cone 球果 + fer）
transfer = 转移

aquiline
核心：指鼻子"鹰钩状的"——高而弯，像鹰喙。
几乎只用在 aquiline nose 这个搭配里。
① He has an aquiline nose.
= 他是鹰钩鼻。
aquiline nose = 鹰钩鼻
② Her aquiline profile was striking.
= 她的侧脸轮廓很突出。
aquiline profile = 鹰钩鼻侧影
③ The portrait shows aquiline features.
= 那幅肖像画出了鹰隼般的五官。
词源：拉丁语 aquila（鹰）
注意：aquiline 是中性偏褒的描述，
指轮廓分明，不是贬义。

arable
核心：指土地"适于耕种的"，与放牧用地相对。
最常见的搭配是 arable land、arable farming。
① Only 10% is arable land.
= 只有一成是耕地。
arable land = 可耕地
② Arable farming dominates here.
= 这里以种植业为主。
arable farming = 种植农业
③ The soil is not arable.
= 那片土壤不宜耕种。
对照：
arable = 种植的（耕地）
pastoral = 放牧的（草场）
fallow = 休耕的

arbiter
核心：指有权裁断的人。两条线：正式的"仲裁人"，
和比喻义的"权威、风向标"（arbiter of taste）。
① He acted as arbiter.
= 他担任了仲裁人。
act as arbiter = 充当裁断者
② She is an arbiter of taste.
= 她是品味的权威。
an arbiter of taste = 品味的仲裁者
③ The court is the final arbiter.
= 法院是最终裁断者。
final arbiter = 最终裁定者
近义对照：
arbiter = 裁断者（有权定夺）
arbitrator = 仲裁员（正式程序）
judge = 法官、评委

arbitrary
核心：指决定"没有依据、全凭个人意志的"，贬义。
数学和技术语境里则是中性的"任意的"。
① It was an arbitrary decision.
= 那是个专断的决定。
arbitrary decision = 独断的决定
② The rule seems arbitrary.
= 那条规则显得没道理。
③ Choose an arbitrary number.
= 任选一个数。
技术语境为中性
副词形式：
arbitrarily = 专断地；任意地
词族：arbitrariness = 任意性

arbitrate
核心：指以第三方身份"仲裁"争端。介词用 in 或 between。
比 mediate 更有约束力——仲裁结果双方须遵守。
① She arbitrated in the dispute.
= 她仲裁了那场纠纷。
arbitrate in = 就…进行仲裁
② A panel arbitrated between them.
= 一个小组在双方之间仲裁。
arbitrate between = 在…之间裁断
③ They agreed to arbitrate.
= 他们同意提交仲裁。
词族：
arbitration = 仲裁
arbitrator = 仲裁员
近义对照：
arbitrate = 仲裁（有约束力）
mediate = 调解（不作决定）

arbitration
核心：指把争端交给中立第三方裁决的"仲裁"程序，
比打官司快且私密。不可数。
① The case went to arbitration.
= 那个案子进入了仲裁。
go to arbitration = 提交仲裁
② They accepted binding arbitration.
= 他们接受了有约束力的仲裁。
binding arbitration = 终局仲裁
③ Arbitration avoids court costs.
= 仲裁能省下诉讼费。
词族：arbitrate、arbitrator
争议解决三途：
negotiation = 谈判（自行解决）
mediation = 调解（有人帮忙）
arbitration = 仲裁（第三方裁决）

arbitrator
核心：指主持仲裁的人，通常由双方共同选定。
和 arbiter 的差别：arbitrator 是正式程序里的角色。
① An arbitrator was appointed.
= 指定了一名仲裁员。
appoint an arbitrator = 任命仲裁员
② The arbitrator ruled in her favour.
= 仲裁员裁定她胜。
rule in someone's favour = 判某人胜
③ Both sides chose the arbitrator.
= 仲裁员由双方共同选定。
词族：arbitrate、arbitration
近义对照：
arbitrator = 仲裁员（有裁决权）
mediator = 调解人（无裁决权）

arc
核心：指弧、弧形轨迹。数学上是圆的一段，
叙事里指 story arc（故事线的起伏走向）。
① The ball traced an arc.
= 球划出一道弧线。
trace an arc = 划出弧线
② Measure the arc of the circle.
= 量一下那段圆弧。
③ The character arc is well written.
= 那个人物弧光写得好。
character arc = 人物成长线
④ An electric arc formed.
= 形成了电弧。
electric arc = 电弧
注意别混：
arc = 弧
ark = 方舟

arcade
核心：三条线：有拱廊的"廊街"、有顶的"商业街"、
以及放街机的"游戏厅"。
① They walked through the arcade.
= 他们穿过了那条拱廊。
② The shopping arcade is covered.
= 那条商业街有顶棚。
shopping arcade = 有顶商业街
③ He played at the arcade.
= 他在游戏厅玩。
arcade game = 街机游戏
词族：
arch = 拱
构词：arc 弧 + -ade

arcane
核心：指知识"深奥难懂、只有内行才明白的"，
常带一点"故弄玄虚"的意味。
① The rules are arcane.
= 那些规则晦涩难懂。
② He knows arcane details.
= 他知道些冷门细节。
arcane detail = 深奥的细节
③ It's arcane knowledge.
= 那是门外汉搞不懂的学问。
arcane knowledge = 秘传知识
近义对照：
arcane = 深奥神秘（内行才懂）
esoteric = 只有小圈子懂的
obscure = 晦涩（不清楚）
abstruse = 艰深（常含批评）

arch
核心：三条线：建筑的"拱"、脚的"足弓"、
以及动词"拱起"。形容词义是"调皮狡黠的"。
① The bridge has three arches.
= 那座桥有三个拱。
② The cat arched its back.
= 那只猫弓起了背。
arch one's back = 弓背
③ He has high arches.
= 他足弓很高。
④ She gave an arch smile.
= 她笑得有点狡黠。
词族：
archway = 拱门
arched = 拱形的
注意复数：arch → arches

archaeological
核心：指"考古学的"。常见搭配 archaeological site、
archaeological evidence、archaeological dig。
① They found an archaeological site.
= 他们发现了一处考古遗址。
archaeological site = 考古遗址
② Archaeological evidence supports it.
= 考古证据支持这一点。
archaeological evidence = 考古证据
③ The dig was archaeological.
= 那次挖掘是考古性质的。
注意英美拼写：
英式 archaeological / 美式 archeological
词族：archaeology、archaeologist

archaeologist
核心：指考古学家——通过发掘遗迹研究古代人类。
和 anthropologist（研究人类社会文化）分工不同。
① Archaeologists uncovered a tomb.
= 考古学家发掘出一座墓。
uncover a tomb = 发掘古墓
② She trained as an archaeologist.
= 她受训成为考古学家。
③ Archaeologists date the finds.
= 考古学家为出土物断代。
date the finds = 给发现物断代
词族：archaeology、archaeological
近义对照：
archaeologist = 考古学家（发掘遗物）
anthropologist = 人类学家（研究社会）
palaeontologist = 古生物学家（研究化石）

archaeology
核心：指考古学——通过物质遗存研究人类历史。不可数。
注意英美拼写差别。
① She studies archaeology.
= 她学考古。
② Archaeology reveals daily life.
= 考古揭示了日常生活。
③ Underwater archaeology is growing.
= 水下考古在发展。
underwater archaeology = 水下考古
注意英美拼写：
英式 archaeology / 美式 archeology
构词：archaeo- 古old + -logy 学科
注意发音：/ˌɑːkiˈɒlədʒi/

archaic
核心：两条线：语言"古体的、已废弃的"，
和事物"陈旧过时的"（贬义）。
① "Thou" is archaic.
= 「thou」是古体词。
archaic word = 古语词
② The system is archaic.
= 那套系统早已陈旧。
archaic system = 老掉牙的体制
③ Archaic laws remain on the books.
= 一些古老法条仍未废止。
注意发音：/ɑːˈkeɪɪk/，
重音在第二音节，ch 读 /k/。
近义对照：
archaic = 古体的；陈旧的
obsolete = 已淘汰的
antiquated = 过时的（贬义）

archbishop
核心：指大主教——管辖一个教省的高级主教，
地位在 bishop 之上。
① The Archbishop of Canterbury spoke.
= 坎特伯雷大主教发了言。
② He was made archbishop.
= 他被任命为大主教。
③ The archbishop led the service.
= 大主教主持了礼拜。
lead the service = 主持礼拜
教阶由高到低：
pope = 教宗
archbishop = 大主教
bishop = 主教
priest = 神父

archer
核心：指射箭的人。射箭这项运动叫 archery。
中世纪战争里 archer 是重要兵种。
① The archer drew his bow.
= 那名弓箭手拉开了弓。
draw a bow = 拉弓
② Archers won the battle.
= 弓箭手赢下了那场战役。
③ She is a skilled archer.
= 她箭术精湛。
词族：
archery = 射箭运动
bow = 弓 / arrow = 箭
quiver = 箭袋

archery
核心：指射箭这项运动，不可数。奥运项目之一。
① He took up archery.
= 他开始练射箭。
take up archery = 学射箭
② Archery requires steady hands.
= 射箭需要手稳。
③ The archery range is outside.

archery range = 射箭场
词族：
archer = 弓箭手

target = 靶
bullseye = 靶心

archetypal
核心：指"典型的、原型式的"——最能代表某一类的。
比 typical 更强调"本源、范式"。
① He's the archetypal English gentleman.
= 他是典型的英国绅士。
archetypal figure = 典型人物
② It's an archetypal love story.
= 那是个原型式的爱情故事。
③ The plot is archetypal.
= 那个情节是经典范式。
词族：archetype
近义对照：
archetypal = 原型式的（本源范式）
typical = 典型的（常见）
quintessential = 精髓的（最纯粹）
