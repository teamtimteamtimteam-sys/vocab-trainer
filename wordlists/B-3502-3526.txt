buggery
核心：法律和正式文本里的用词，指肛交，历史上曾是罪名。
今天多数英语国家已废除相关罪名，这个词主要出现在旧法条、
历史叙述和法律史讨论里。英式口语里另有一个骂人的固定说法
用到它，语气很重。不可数。
① Buggery was a criminal offence until 1967.
= 那项罪名到一九六七年才废。
buggery = 肛交（法律用语）
② Old statutes list buggery among the felonies.
= 旧法条把它列在重罪里。
list among the felonies = 列为重罪
注意语域：法律与历史文本用词，
日常不用。

buggy
核心：三支。名词最常用的是婴儿推车，英式说 buggy，
美式说 stroller。也指轻便的小车：旧时是单马拉的双轮马车，
今天多指沙滩车和高尔夫球车。形容词那一支从 bug 来：
程序毛病多的，说软件 buggy 是"一堆 bug"。可数。
① She pushed the buggy up the hill.
= 她把婴儿车推上了坡。
a buggy = 婴儿推车（英式）
② They hired a beach buggy.
= 他们租了辆沙滩车。
a beach buggy = 沙滩车
③ The app is still buggy.
= 那个应用毛病还很多。
buggy = 程序缺陷多的
构词：来历不明；形容词义来自 bug
注意地域：
buggy = 婴儿推车（英式）
stroller = 婴儿推车（美式）

bugle
核心：一种铜管乐器，形状像小号却没有活塞键——正因为没有键，
它只吹得出泛音列上那几个音，所以只能用来吹信号：
起床号、熄灯号、冲锋号。军队和童军里用得最多。可数。
① The bugle sounded at dawn.
= 天亮时号声响起。
sound = 响起
② A bugle has no valves.
= 军号没有活塞键。
valve = 活塞键
③ He played the last post on a bugle.
= 他用军号吹了熄灯号。
构词：拉丁语 buculus 小公牛（最早用牛角做）
注意用法：没有键，只吹得出有限几个音，
所以专用来吹信号。

bugler
核心：吹军号的人。在军队编制里这是个正式岗位：作息、集合、
冲锋、葬礼都靠他吹号传令。今天多见于仪式场合——
阵亡将士纪念仪式上吹熄灯号的就是他。可数。
① The bugler stood to attention.
= 号手立正站着。
stand to attention = 立正
② A bugler sounded the last post.
= 号手吹响了熄灯号。
③ Every regiment had its buglers.
= 每个团都有自己的号手。
构词：bugle 军号 + -er

build
核心：底层是"一点一点搭起来"。盖房子是本义；抽象一路是
逐步建立——建立名声、建立信任、积累经验都用它。
名词那一支容易漏：指人的体格，a slim build 是身材瘦削。
短语动词成族：build up 是积累增强，build on 是在已有基础上
再往上加，build in 是把某样东西做进去、内置。
三态不规则：build / built / built。
① They built a new bridge.
= 他们建了座新桥。
② She built a reputation for honesty.
= 她建立起了诚实的名声。
build a reputation = 建立名声
③ He is of medium build.
= 他中等身材。
build = 体格、身材
④ Pressure built up over months.
= 压力积了好几个月。
build up = 逐渐积累、增强
⑤ The plan builds on earlier work.
= 那个方案是在前人工作上做的。
build on = 以某物为基础往上做
⑥ Safeguards are built in.
= 保障措施是内置的。
build in = 内置、做进去
⑦ The course is built around case studies.
= 那门课是围绕案例设计的。
build around = 围绕某物来构建
⑧ Safeguards are built into the system.
= 保障机制做进了系统里。
build into = 把某物做进去
⑨ They built a porch onto the house.
= 他们给房子加建了个门廊。
build onto = 在原有建筑上加建
⑩ The film builds up to a twist.
= 那部片子层层铺垫到一个反转。
build up to = 逐步铺垫到
构词：古英语 byldan
注意三态：build / built / built
词族：
builder = 建筑工；建造者
building = 建筑物

builder
核心：盖房子的人或公司——英式尤指做房屋施工和翻修的工头与
工人，说 get a builder in 是"找施工的来"。它也用在抽象义上：
a builder of consensus 是把共识一点点建起来的人。可数。
① They got a builder in to quote.
= 他们找了施工的来报价。
quote = 报价
② The builders start on Monday.
= 施工的周一开工。
③ She is a builder of consensus.
= 她善于把共识建立起来。
a builder of = 某事的建立者
构词：build 建造 + -er
注意用法：英式尤指做房屋施工与翻修的人。

building
核心：两支。一是建筑物，一栋有墙有顶的房子，这是最常用的。
二是建造这件事本身，不可数——building work 是施工，
building site 是工地。它跟 house 的分界：house 特指住人的，
building 什么用途都可以。
① The building has ten floors.
= 那栋楼有十层。
② Building work starts next week.
= 施工下周开始。
building work = 建筑施工
③ Keep off the building site.
= 工地请勿入内。
a building site = 工地
④ Trust is a building block of teamwork.
= 信任是团队合作的基石。
building block = 积木；也指最基本的组成部分
构词：build 建造 + -ing
注意别混：
building = 建筑物（任何用途）
house = 住宅（专指住人的）

building society
核心：英式的一类金融机构，由会员共同拥有，主要业务是收存款、
放房贷。它跟银行的根本分别在归属：building society 归存款的
会员所有，银行归股东所有，所以前者的盈利理论上回到会员身上。
可数。
① She has a building society account.
= 她在建房互助会开了户。
an account = 账户
② Building societies are owned by members.
= 那类机构归会员所有。
be owned by = 归……所有
构词：building 建房 + society 会社
注意别混：
building society = 会员共有的储贷机构（英式）
bank = 银行（股东所有）

built
核心：build 的过去式和过去分词，三态是 build / built / built。
它还大量作形容词用，前面加个词说明"怎么造的"或"怎么长的"：
built-in 是内置的，purpose-built 是为特定用途专门造的，
well-built 说人是身材壮实、说房子是造得结实，
custom-built 是定制的。
① The house was built in 1890.
= 那栋房子建于一八九零年。
被动语态用 built。
② The flat has built-in wardrobes.
= 那套房带内置衣柜。
built-in = 内置的
③ The hall is purpose-built.
= 那个厅是为此专门建的。
purpose-built = 为特定用途专建的
④ He is tall and well-built.
= 他个子高、身板结实。
well-built = 身材结实的；造得结实的
⑤ They live in a built-up area.
= 他们住在建筑密集区。
built-up = 建筑密集的；也指累积起来的
构词：build 的过去式与过去分词
注意三态：build / built / built

bulb
核心：两支，共通处是那个圆鼓鼓的形状。一是灯泡；
二是球茎——郁金香水仙洋葱底下那个鼓起来的部分，
把养分存在里面过冬。哪一支得看语境，园艺文里说 bulb 一定是
球茎，家里说换 bulb 一定是灯泡。可数。
① The bulb has blown.
= 灯泡烧了。
a bulb blows = 灯泡烧掉
② Change the bulb in the hall.
= 把门厅的灯泡换了。
③ Plant the bulbs in autumn.
= 球茎秋天种下去。
plant bulbs = 种球茎
④ Tulips grow from bulbs.
= 郁金香是从球茎长出来的。
构词：拉丁语 bulbus 洋葱
注意用法：两支靠语境分，园艺文里一定是球茎。

bulbous
核心：形容词，圆鼓鼓的、像球茎一样往外鼓的。它最常见的搭配是
a bulbous nose——鼓起的酒糟鼻，用来说人多少带点不客气。
也说船首、说建筑、说植物的形状。
① He has a bulbous nose.
= 他鼻头鼓鼓的。
a bulbous nose = 鼓起的大鼻头
② The ship has a bulbous bow.
= 那艘船是球鼻艏。
a bulbous bow = 球鼻艏
③ The dome looks bulbous.
= 那个穹顶鼓鼓囊囊的。
构词：bulb 球茎 + -ous
注意语用：说人的鼻子时带一点不客气。

bulgar
核心：粗麦粉——小麦粒煮过、烘干再碾碎，所以泡一泡就能吃，
不用久煮。中东菜里的塔布勒沙拉用的就是它。
更常见的拼法是 bulgur，两种都通行。不可数。
① Soak the bulgar in hot water.
= 把粗麦粉用热水泡开。
soak = 浸泡
② Bulgar is precooked wheat.
= 粗麦粉是预煮过的麦粒。
precooked = 预先煮过的
③ The spelling bulgur is more common.
= 「bulgur」那个拼法更常见。
构词：土耳其语 bulgur
注意拼写：bulgur 更常见，bulgar 也通行。

bulge
核心：从平的表面上鼓出来的一块。名词动词同形。
说口袋里塞了东西鼓起来、说墙面凸出、说肚子鼓，都用它。
引申一支在统计和人口上：a bulge in the numbers 是数字上
一段异常的隆起，战后婴儿潮就常被说成 the postwar bulge。
可数。
① His pocket had a strange bulge.
= 他口袋鼓出一块，看着怪。
② The wall bulged outwards.
= 那面墙往外凸了。
bulge outwards = 向外鼓出
③ The bag was bulging with books.
= 那个包塞满了书鼓鼓的。
bulge with = 塞满而鼓起
④ There is a bulge in the age group.
= 那个年龄段人数明显隆起。
a bulge = 数量上的一段隆起
构词：拉丁语 bulga 皮袋
词族：
bulging = 鼓鼓的；塞满的

bulging
核心：形容词，鼓鼓的、撑得满满的。两种常见用法：
说容器是塞得太满，a bulging suitcase 是撑得关不上的箱子；
说眼睛是瞪得凸出，bulging eyes 多因惊恐或用力。
也说肌肉鼓起。
① He carried a bulging suitcase.
= 他提着个撑得鼓鼓的箱子。
a bulging suitcase = 塞得满满的箱子
② She stared with bulging eyes.
= 她瞪着眼睛盯着看。
bulging eyes = 瞪凸的眼睛
③ His arms were bulging with muscle.
= 他胳膊上肌肉鼓鼓的。
构词：bulge 鼓出 + -ing

bulimia
核心：一种进食障碍，特点是暴食之后再想办法把吃进去的弄出来。
它跟厌食症 anorexia 的分别常被混：厌食是极力少吃，
贪食是先吃后清，体重未必看得出来。全称是 bulimia nervosa。
不可数。
① She was treated for bulimia.
= 她因贪食症接受了治疗。
be treated for = 因某病接受治疗
② Bulimia often goes unnoticed.
= 贪食症常常不被察觉。
go unnoticed = 未被注意到
③ The full name is bulimia nervosa.
= 全称是神经性贪食症。
构词：希腊语 bous 牛 + limos 饥饿
注意别混：
bulimia = 贪食症（先暴食再设法清除）
anorexia = 厌食症（极力少吃）

bulimic
核心：形容词也作名词，指患贪食症的或那样的患者。
今天医学和媒体写作里越来越少用它当名词直接指人——
说 a person with bulimia 比说 a bulimic 得体，
因为后者等于用病名定义整个人。
① She was bulimic for years.
= 她有好些年患着贪食症。
② Bulimic behaviour is often hidden.
= 贪食症的行为常被藏起来。
hidden = 藏着的
③ The preferred wording is a person with bulimia.
= 更得体的说法是「患贪食症的人」。
preferred = 更可取的
构词：bulimia 贪食症 + -ic
注意语用：当名词直接指人不够得体，
今天多说 a person with bulimia。

bulk
核心：底层是"很大的体量"。说物体是笨重的块头，his bulk
filled the doorway 是他那身子把门堵满了。最常用的两支是搭配：
the bulk of 是"大部分"，in bulk 是"大批量地"——
buy in bulk 是整批买，便宜。动词是使显得庞大，
bulk up 是练壮或把分量堆大。不可数。
① He lowered his bulk into the chair.
= 他把那身子沉进椅子里。
② The bulk of the money is gone.
= 那笔钱大半没了。
the bulk of = 大部分
③ They buy in bulk to save money.
= 他们整批采购省钱。
in bulk = 大批量地
④ He is bulking up for the season.
= 他为赛季在增重练壮。
bulk up = 增重练壮
⑤ Rice bulks out the stew.
= 加米能把那锅炖菜撑得多些。
bulk out = 使分量显得更多
构词：古诺斯语 bulki 货堆
注意用法：the bulk of 和 in bulk 是两个高频搭配。

bulkhead
核心：船舱和机舱里的隔板，把内部分成互不相通的若干段。
它要紧在防沉：一处破了进水，水被隔板挡在那一段里，
船还浮得住。飞机上分舱的那道板也叫它，
所以订票时说 bulkhead seat 是紧挨隔板的座位。可数。
① Water was held back by the bulkhead.
= 水被隔板挡住了。
hold back = 挡住
② He booked a bulkhead seat.
= 他订了紧挨隔板的座位。
a bulkhead seat = 隔板前的座位
③ The bulkheads divide the hull.
= 那些隔板把船体分成几段。
divide = 分隔
构词：bulk 货堆 + head 隔断
注意用法：一处进水被隔在一段里，船才不沉。

bulky
核心：形容词，又大又占地方、不好搬不好放的。它说的不是重
而是"体积大"——一床被子不沉却很 bulky。常用来说包裹、
行李、家具和衣服，多带一点嫌麻烦的意味。
① The parcel is too bulky to post.
= 那个包裹太大，寄不了。
too bulky to = 大得没法……
② He wore a bulky jumper.
= 他穿了件厚墩墩的毛衣。
a bulky jumper = 厚而蓬的毛衣
③ Bulky items cost more to ship.
= 大件东西运费更高。
构词：bulk 体量 + -y
注意别混：
bulky = 占地方的（重在体积）
heavy = 沉的（重在重量）

bull
核心：底层是公牛，也指象、鲸、海豹这些大兽的雄性——
bull elephant 是公象。从公牛"猛冲上涨"的画面引申出金融义：
bull market 是牛市，看涨的人叫 a bull。另有一支纯口语：
bull 是 bullshit 的委婉缩略，指胡说。习语几个都很常用：
take the bull by the horns 是迎难而上，
a bull in a china shop 是莽撞闯祸的人，
like a red rag to a bull 是火上浇油。还有一支毫不相干：
papal bull 是教皇诏书，来自那份文书上的铅印。
① The bull charged the fence.
= 那头公牛冲向围栏。
② A bull elephant guarded the herd.
= 一头公象护着象群。
bull = 大型动物的雄性
③ Shares rose in a bull market.
= 股价在牛市里上涨。
bull market = 牛市、看涨行情
④ That is a load of bull.
= 那全是胡扯。
bull = 胡说（bullshit 的委婉缩略）
⑤ She took the bull by the horns.
= 她迎难而上。
take the bull by the horns = 硬着头皮直面难题
⑥ He is a bull in a china shop.
= 他是个莽撞闯祸的家伙。
a bull in a china shop = 莽撞笨拙、一碰就坏事的人
⑦ The remark was like a red rag to a bull.
= 那句话等于火上浇油。
like a red rag to a bull = 惹人发作的东西
⑧ The truck has bull bars.
= 那辆卡车装着前护杠。
bull bars = 车头防撞护杠
⑨ They kept a bull mastiff.
= 他们养了条斗牛獒。
bull mastiff = 斗牛獒
⑩ They had a late-night bull session.
= 他们熬夜闲聊了一场。
bull session = 一群人漫无边际的闲聊（美式）
⑪ The bull terrier has an egg-shaped head.
= 斗牛梗的头是蛋形的。
bull terrier = 斗牛梗
⑫ The term bull dyke is a slur.
= 那个说法是句侮辱语。
bull dyke = 对外表偏男性化的女同性恋者的侮辱称呼
明确的冒犯语，读到要懂，任何场合都不要用。
构词：古诺斯语 boli
词族：
bullish = 看涨的；牛气的

bulldog
核心：一种矮壮的犬，头大、口鼻扁塌、下颌前突。名字来自
它的旧用途：bull-baiting，一种拿狗咬公牛的旧式娱乐，
后来被禁。今天这个词更常用在比喻上：
bulldog spirit 指咬住不放、绝不退让的那股劲，
在英国带着强烈的民族意象。可数。
① The bulldog refused to let go.
= 那条斗牛犬咬住就不松口。
let go = 松开
② They showed bulldog spirit.
= 他们表现出咬住不放的韧劲。
bulldog spirit = 顽强不退让的劲头
构词：bull 公牛 + dog 狗
注意来历：名字来自那种已被禁止的旧式娱乐。

bulldoze
核心：本义是用推土机把地面推平、把房子推倒。引申义用得更多：
不顾反对硬推——bulldoze a plan through 是把方案强行推过去，
bulldoze someone into doing something 是硬压着人做事。
它带明确的批评：说的是不听意见、碾过去。及物。
① They bulldozed the old terrace.
= 他们把那排老房推平了。
② He bulldozed the proposal through.
= 他把那个提案强行推了过去。
bulldoze through = 强行推动通过
③ She was bulldozed into signing.
= 她是被硬压着签的字。
bulldoze someone into = 强压某人做某事
构词：bull 公牛 + doze 猛击（旧俚语）
注意语用：引申义带明确批评。

bulldozer
核心：推土机，前面装一块大铲板把土石推开的工程车。
引申指那种不听劝、硬往前推的人，说 he is a bulldozer
是在说他碾过所有反对意见——跟动词 bulldoze 一样带批评。
可数。
① A bulldozer cleared the site.
= 一台推土机把工地清了出来。
clear = 清理
② As a manager he is a bulldozer.
= 他当管理者是个碾着人往前推的。
指人那一支，带批评。
构词：bull 公牛 + doze 猛击
词族：
bulldoze = 推平；强行推进

bullet
核心：两支。一是枪弹的弹头，从枪口飞出去的那一颗。
二是排版里的项目符号：列表每一条前面那个圆点，
所以 bullet point 是"要点条目"，presentations 里最常见。
两个高频习语：bite the bullet 是硬着头皮扛下来，
dodge a bullet 是险险躲过一劫。可数。
① The bullet missed him.
= 那颗子弹没打中他。
miss = 没打中
② Summarize it in three bullets.
= 用三条要点概括。
a bullet = 项目符号条目
③ Put it in bullet points.
= 写成要点条列。
bullet point = 要点条目
④ We had to bite the bullet.
= 我们只好硬扛下来。
bite the bullet = 硬着头皮承受
⑤ He dodged a bullet there.
= 他那回是险险躲过。
dodge a bullet = 侥幸避开一场麻烦
构词：法语 boulette 小球
词族：
bulleted = 带项目符号的

bullet train
核心：高速列车的通俗说法，最早指日本的新干线——车头流线型
像子弹，名字由此而来。今天泛指各国的高铁，
新闻里用它比说 high-speed rail 更口语。可数。
① They took the bullet train to Kyoto.
= 他们坐新干线去了京都。
take a train = 乘火车
② The bullet train runs every ten minutes.
= 高速列车每十分钟一班。
构词：bullet 子弹 + train 列车
近义对照：
bullet train = 高速列车（通俗说法）
high-speed rail = 高速铁路（正式说法）
