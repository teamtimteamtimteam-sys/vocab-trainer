appetite
核心：字面是"食欲"，比喻是对某事的"强烈欲望"。loss of appetite
是医学常用表达；appetite for 后面可以接任何想要的东西。
① She has a good appetite.
= 她胃口很好。
② I've lost my appetite.
= 我没胃口了。
lose one's appetite = 没胃口
③ He has an appetite for risk.
= 他有冒险的欲望。
appetite for = 对…的强烈欲望
④ The smell whetted my appetite.
= 那香味勾起了我的食欲。
whet one's appetite = 引起兴趣
词族：
appetizer = 开胃菜
appetizing = 开胃的、诱人的

appetizer
核心：指正餐前的"开胃菜、前菜"。美式常用，
英式更常说 starter。也拼作 appetiser。
① We ordered appetizers.
= 我们点了几道前菜。
② The appetizer was excellent.
= 那道开胃菜很棒。
③ Shrimp makes a good appetizer.
= 虾做前菜很合适。
注意英美差别：
美式 appetizer / 英式 starter
注意拼写：appetizer / appetiser 都可以。
一餐的顺序：
starter / appetizer = 前菜
main course = 主菜
dessert = 甜点

appetizing
核心：指食物"看着诱人、让人有食欲的"。
否定形式 unappetizing 用得同样多。
① The smell is appetizing.
= 那香味很诱人。
appetizing smell = 诱人的香味
② It looks appetizing.
= 看着就有食欲。
③ The photo made it appetizing.
= 那张照片拍得让人想吃。
反义词：
unappetizing = 倒胃口的
词族：
appetite = 食欲
appetizer = 开胃菜
注意拼写：appetizing / appetising 都可以。

applaud
核心：字面是"鼓掌"，比喻是"称赞、赞许"。后者在正式文体里很常见，
比如 applaud a decision。及物不及物都可以。
① The audience applauded loudly.
= 观众热烈鼓掌。
② They applauded her courage.
= 他们称赞她的勇气。
这里：
applaud = 赞许
③ I applaud the decision.
= 我对这个决定表示赞赏。
词族：
applause = 掌声（不可数）
注意：applause 不可数，
不说 an applause、applauses。

applause

apple
核心：指苹果。构词和习语能力极强：apple pie、
the apple of one's eye（掌上明珠）、Adam's apple（喉结）。
① She ate an apple.
= 她吃了个苹果。
② Apple pie is a classic dessert.
= 苹果派是道经典甜点。
apple pie = 苹果派
③ She's the apple of his eye.
= 她是他的掌上明珠。
the apple of one's eye = 心头至爱
④ An apple a day keeps the doctor away.
= 一天一苹果，医生远离我。
常用搭配：
Adam's apple = 喉结
upset the apple cart = 打乱计划
⑤ The child was apple-cheeked and shy.
= 那孩子脸蛋红扑扑的，有点怕生。
apple-cheeked = 双颊红润的
⑥ They pressed apple cider in autumn.
= 他们秋天压苹果汁。
apple cider = 苹果汁；苹果酒（美式指未发酵的）
⑦ The students made him an apple-pie bed.
= 学生给他做了个恶作剧短床。
apple-pie bed = 恶作剧短床（把床单折起来让人伸不直腿）
⑧ The workshop is in apple-pie order.
= 那间工坊收拾得井井有条。
apple-pie order = 井井有条
⑨ Serve the pork with apple sauce.
= 猪肉配苹果酱吃。
apple sauce = 苹果酱
⑩ He poured a measure of applejack.
= 他倒了一杯苹果白兰地。
applejack = 苹果白兰地（美式）
⑪ The page runs a small applet.
= 那个页面跑着一个小程序。
applet = 小应用程序

appliance
核心：指家用电器和器具，比 device 大件、比 machine 日常。
最常见的是 household appliance、kitchen appliance。
① They sell household appliances.
= 他们卖家用电器。
household appliance = 家用电器
② The appliance broke down.
= 那件电器坏了。
③ Kitchen appliances take up space.
= 厨房电器很占地方。
词族：
apply = 应用
近义对照：
appliance = 家电器具（洗衣机、冰箱）
device = 装置（小型、常带电子）
gadget = 小玩意（新奇小巧）
machine = 机器（通用）

applicable
核心：指规则、条款"适用的"。介词用 to。
表格里的 N/A 就是 not applicable（不适用）。
① The rule is applicable to everyone.
= 那条规则适用于所有人。
applicable to = 适用于
② Write N/A if not applicable.
= 不适用就填 N/A。
not applicable = 不适用
③ These terms are applicable here.
= 这些条款在此适用。
注意发音：
重音可在第一或第二音节，
/ˈæplɪkəbl/ 与 /əˈplɪkəbl/ 都通行。
词族：apply = 适用

applicant
核心：指申请人——申请工作、学校、签证、贷款的人。
构词是 apply + -ant（做…的人）。
① There were 200 applicants.
= 有两百名申请人。
② Successful applicants will be contacted.
= 入选者会收到通知。
successful applicant = 获录取者
③ Applicants must submit references.
= 申请人须提交推荐信。
词族：
apply = 申请
application = 申请
构词：-ant 表示做某事的人
同类：assistant、participant、accountant

application
核心：三条线：申请（申请书）、应用（把理论用到实处）、以及电脑上的
应用程序。第三个义现在最常用，缩写就是 app。
① I submitted my application.
= 我提交了申请。
② Fill in the application form.
= 填写申请表。
application form = 申请表
③ It has practical applications.
= 它有实际用途。
这里：
application = 应用
④ Download the application.
= 下载那个应用程序。
缩写为 app。
⑤ Apply two applications of paint.
= 刷两遍漆。
这里：
application = 涂敷（一次）
词族：applicant = 申请人
⑥ The service exposes an application programming interface.
= 那项服务开放了应用程序接口。
application programming interface = 应用程序接口
⑦ They questioned the applicability of the rule.
= 他们质疑那条规则是否适用。
applicability = 适用性
⑧ Use the applicator to spread the gel.
= 用涂敷器把凝胶抹开。
applicator = 涂敷器、施药器

applied
核心：指学科"应用型的"，与 pure（纯理论的）相对。
只作定语。applied science、applied linguistics。
① She studies applied mathematics.
= 她学应用数学。
applied mathematics = 应用数学
② Applied research has practical aims.
= 应用研究有实际目标。
applied research = 应用研究
③ It's a course in applied linguistics.
= 那是门应用语言学课程。
反义对照：
applied = 应用的（解决实际问题）
pure = 纯理论的（不问用途）
theoretical = 理论的

appliqué
核心：法语借词，指"贴布绣"——把剪好的布片缝贴到底布上拼成图案，
不是绣线绣出来的。既作名词指这种工艺和成品，也作动词。
过去分词写作 appliquéd。词尾那个字母上的尖音符不能省。
① The quilt is decorated with appliqué.
= 那床被子上有贴布绣装饰。
decorated with appliqué = 以贴布绣装饰
② She appliquéd flowers onto the hem.
= 她在下摆上贴绣了花。
appliquéd = 贴布绣成的
③ Appliqué work covers the cushion.
= 那个靠垫上满是贴布绣。
appliqué work = 贴布绣活计
注意拼写：
词尾带尖音符，省掉就成了别的词。
工艺对照：
appliqué = 贴布绣（缝贴布片）
embroidery = 刺绣（用线绣）
patchwork = 拼布（布片彼此缝合成面）

apply
核心：底层是"把某物贴到、用到某处"。申请是"把自己递上去"，应用是

④ Apply the cream twice daily.
= 每天涂两次药膏。
这里：
apply = 涂抹

appoint

appointment

apportion

apposition
核心：底层是"并排摆在一起"。语法上指"同位语"——两个成分挨着放、
指的是同一个东西，后一个给前一个作补充说明。形容词 appositional。
同源的 apposite 是另一路意思：指话说得"贴切、正合适"。
① "My brother, a doctor" is in apposition.
= 那个结构里后半是同位语。
in apposition = 处于同位关系
② Apposition needs no conjunction.
= 同位语之间不用连词。
③ The clause has an appositional function.
= 那个从句起同位说明的作用。
appositional = 同位的
④ She made an apposite remark.
= 她说了句很贴切的话。
apposite = 贴切的、恰当的
⑤ The quotation is apposite to the argument.
= 那句引文正好切合论点。
apposite to = 切合…
注意别混：
apposition = 同位（语法结构）
apposite = 贴切的（形容说得对路）
opposite = 相反的（毫不相干）
