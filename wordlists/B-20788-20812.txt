= 他家在那家足球俱乐部持有大量股份，所以他每场比赛都有免费票。
a large shareholding = 大量股份

shareware
/ˈʃeəweə(r)/
核心：名词，不可数：共享软件（可免费试用、满意后再付费的软件）。
① In the 1990s, many people downloaded games as shareware and paid only if they liked them.
= 二十世纪九十年代，很多人把游戏当共享软件下载，喜欢才付钱。
shareware = 共享软件
② The program started as shareware, but now you have to buy it before you can use it.
= 那个程序一开始是共享软件，但现在得先买才能用。
start as shareware = 起初是共享软件
