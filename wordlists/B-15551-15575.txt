obdurate
/ˈɒbdjʊrət/
核心：顽固的、执拗不改的：别人怎么劝、怎么求都不肯改变主意。形容词，正式，多含贬义。
名词 obduracy 与副词 obdurately 并入本条。
① The minister remained obdurate despite a petition signed by a million people.
= 尽管有一百万人签名请愿，那位大臣依旧不为所动。
remain obdurate = 依旧不为所动
② The strike dragged on because of the obduracy of both sides.
= 因为双方都执拗不让，罢工拖了下去。
the obduracy of somebody = 某人的执拗
③ He obdurately refused to sign until every clause had been read aloud.
= 他执意不肯签字，非要把每一条都念出来不可。
obdurately refuse = 执意不肯

obedient
/əˈbiːdiənt/
核心：服从的、听话的：照别人说的去做，介词用 to。形容词，反义 disobedient。
名词 obedience 与副词 obediently 并入本条。
① The dog is so obedient that it sits the moment she raises a finger.
= 那条狗很听话，她一抬手指它就坐下。
be obedient = 听话
obedient = 听话的
② The soldiers were expected to be obedient to their officers without question.
= 士兵们被要求对军官绝对服从。
be obedient to somebody = 服从某人
③ The order demands complete obedience from every monk.
= 那个修会要求每位修士绝对服从。
obedience = 服从
④ The children lined up obediently and waited for the bell.
= 孩子们乖乖排好队，等着打铃。
obediently = 乖乖地

obeisance
/əʊˈbeɪsəns/

① Every visiting leader is expected to pay obeisance to the old general.

= 女王走进大厅的时候，朝臣们深深鞠躬。
make an obeisance = 行礼

obelisk
/ˈɒbəlɪsk/
核心：方尖碑：一根四面、上细下粗、顶端呈金字塔形的高石柱，古埃及最先建造，后世多用作纪念碑。可数。
① An Egyptian obelisk stands in the middle of the square, far from the temple it once guarded.
= 一座埃及方尖碑立在广场中央，离它从前守护的神庙很远。
an obelisk = 方尖碑
② The names of the dead are carved on a granite obelisk beside the church.
= 死者的名字刻在教堂旁的一座花岗岩方尖碑上。
a granite obelisk = 花岗岩方尖碑

obese
/əʊˈbiːs/

= 医生直截了当地告诉他，他属于肥胖，有患糖尿病的风险。

③ Obesity has doubled in the country in a single generation.
= 该国的肥胖率在一代人的时间里翻了一番。
obesity = 肥胖、肥胖症

object
/ˈɒbdʒɪkt/（名）/əbˈdʒekt/（动）
核心：名词与动词重音不同。名词四支：一是物体、东西，可数：a metal object；
二是（感情、行为的）对象：the object of 加抽象名词，an object of pity 是让人可怜的对象；
三是目的、目标，单数：the object of the exercise 是这么做的目的；四是（语法）宾语：the direct object。
动词：反对、不赞成：介词用 to，后面接名词或动名词；也引出反对的话。
习语 money is no object 是钱不成问题。
① The police found a heavy metal object wrapped in a towel under the seat.
= 警察在座位底下找到一件用毛巾裹着的沉甸甸的金属物品。
a metal object = 金属物品
② A small bright object moved slowly across the sky and vanished.
= 一个明亮的小东西缓缓划过天空，然后不见了。
an object = 物体
③ The new statue has become an object of ridicule in the town.
= 那座新雕像成了镇上人取笑的对象。
an object of ridicule = 取笑的对象
④ She was the object of his affection for thirty years and never knew it.
= 三十年里她一直是他爱慕的对象，自己却毫不知情。
the object of somebody's affection = 某人爱慕的对象
⑤ The object of the exercise is to cut costs without losing staff.
= 这么做的目的，是在不裁员的前提下削减开支。
the object of the exercise = 这么做的目的
⑥ In "She fed the cat", the cat is the direct object of the verb.
= 在这个例句里，猫是动词的直接宾语。
the direct object = 直接宾语
⑦ Many residents object to the plan to build a road through the park.
= 许多居民反对在公园里修路的计划。
object to = 反对
object to something = 反对某事
⑧ I object to being spoken to as if I were a child.
= 我反对别人像对小孩那样跟我说话。
object to doing something = 反对做某事
介词 to 后面接动名词。
⑨ "That is hardly fair," she objected, putting down her fork.
= 「这可不公平。」她放下叉子，表示反对。
somebody objected = 某人表示反对
⑩ He wants the best seats in the house, and money is no object.
= 他要全场最好的座位，钱不成问题。
money is no object = 钱不成问题
⑪ The rescue was an object lesson in how to stay calm.
= 那次救援是如何保持冷静的活生生的一课。
object lesson = 活生生的实例
an object lesson in something = 某事的活教材
⑫ The compiler turns the program into object code that the machine can run.
= 编译器把程序变成机器能运行的目标代码。
object code = 目标代码
⑬ The course teaches object-oriented programming in the second term.
= 那门课第二学期教面向对象的编程。
object-oriented = 面向对象的

objection

obliviously = 浑然不觉地

oblong
/ˈɒblɒŋ/
核心：两支。一是名词，长方形，可数，英式说法；美式里指任何长形（包括长椭圆形）；二是形容词，长方形的、长形的。
① Cut the pastry into an oblong about twice as long as it is wide.
= 把面皮切成一个长约为宽两倍的长方形。
an oblong = 长方形
② The parcel was a flat oblong box tied with green ribbon.
= 那个包裹是一只扁扁的长方形盒子，扎着绿丝带。
an oblong box = 长方形的盒子

obloquy
/ˈɒbləkwi/
核心：两支，正式，不可数。一是公开的辱骂、痛斥；二是因受众人谴责而来的耻辱、坏名声。
① The judge was subjected to public obloquy for the lightness of the sentence.
= 那位法官因为判得太轻，遭到公众的痛斥。
public obloquy = 公众的痛斥
② He died in obloquy, and his name was removed from the school gates.
= 他在骂名中死去，名字也从校门上摘掉了。
die in obloquy = 在骂名中死去

obnoxious
/əbˈnɒkʃəs/
核心：极其讨厌的、可憎的：多说人、行为、气味。形容词，语气很重。副词 obnoxiously 并入本条。
① He becomes loud and obnoxious after his third glass of wine.
= 喝到第三杯酒，他就变得又吵又讨人嫌。
loud and obnoxious = 又吵又讨人嫌
② An obnoxious smell of burning rubber drifted in from the yard.
= 一股烧橡胶的恶臭从院子里飘进来。
an obnoxious smell = 恶臭
③ The man in front talked obnoxiously on his phone through the whole film.
= 前排那个男人整场电影都在大声打电话，烦人透顶。
obnoxiously = 讨人嫌地

oboe
/ˈəʊbəʊ/
核心：双簧管：一种木管乐器，音色尖而带鼻音，乐队调音时由它给出标准音。可数。演奏者叫 oboist，并入本条。
① She plays the oboe in the school orchestra and the piano at home.
= 她在学校乐队里吹双簧管，在家弹钢琴。
play the oboe = 吹双簧管
② The orchestra tunes to an A given by the first oboe.
= 乐队照着首席双簧管给出的标准音调弦。
the first oboe = 首席双簧管
③ The oboist makes her own reeds from cane and a sharp knife.
= 那位双簧管手用芦竹和一把快刀自己做簧片。
an oboist = 双簧管手
