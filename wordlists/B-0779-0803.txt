alleluia
核心：源自希伯来语的赞颂语，意思是"赞美主"，礼拜和圣歌里唱它。
也拼作 hallelujah。日常引申着用，表示"总算好了"的如释重负。
① The choir sang alleluia.
= 唱诗班唱起了哈利路亚。
sing alleluia = 唱哈利路亚
② Alleluia, the rain has stopped.
= 谢天谢地，雨停了。
③ The word alleluia comes from Hebrew.
= 这个赞颂语来自希伯来语。
注意拼写：
alleluia = 哈利路亚（拉丁式拼法）
hallelujah = 哈利路亚（英语常见拼法）
注意语域：
宗教礼仪用语，也作口语感叹。

allergen
核心：指引起过敏反应的"过敏原"，如花粉、尘螨、坚果。
医学和食品标签用语。可数。

= 花粉是常见过敏原。
common allergen = 常见过敏原
② Labels must list allergens.
= 标签必须标明过敏原。
list allergens = 标注过敏原
③ They removed the allergen.
= 他们去除了那种过敏原。
词族：
allergy = 过敏
allergic = 过敏的
构词：allerg- 过敏 + -gen 产生者
同类构词：
carcinogen = 致癌物
pathogen = 病原体

alleviate
核心：指"减轻（痛苦、问题、负担）"，正式用语。宾语一定是不好的
东西：pain、poverty、stress、symptoms。不能说 alleviate happiness。
① The drug alleviates pain.
= 那种药能减轻疼痛。
alleviate pain = 缓解疼痛
② Measures to alleviate poverty are needed.
= 需要扶贫措施。
alleviate poverty = 减轻贫困
③ It alleviated my concerns.
= 那减轻了我的顾虑。
词族：
alleviation = 缓解
近义对照：
alleviate 减轻（正式，宾语是坏事）
relieve 缓解（通用）
ease 减轻（较口语）
mitigate 缓和（减轻严重程度）

alley

bowling alley = 保龄球馆
注意复数：alley → alleys

alligator
核心：指短吻鳄，主要产于美国东南部和中国长江。
和 crocodile（鳄鱼，吻部尖长）是不同物种。
① An alligator basked on the bank.
= 一条短吻鳄在岸边晒太阳。
bask on the bank = 在岸边晒太阳
② Alligators live in fresh water.
= 短吻鳄生活在淡水里。
③ She carries an alligator handbag.
= 她拎着个鳄鱼皮包。
alligator handbag = 鳄鱼皮手袋

alligator = 短吻鳄（吻宽圆，闭嘴看不见下齿）
crocodile = 鳄鱼（吻尖长，闭嘴露出下齿）
caiman = 凯门鳄（南美）
④ Clip the wire with an alligator clip.
= 用鳄鱼夹夹住那根线。
alligator clip = 鳄鱼夹
⑤ Alligator pear is an old name for avocado.
= 鳄梨是牛油果的旧称。
alligator pear = 鳄梨（牛油果的旧称）

alliteration
核心：修辞手法，指相邻词以相同辅音开头，
如 "Peter Piper picked"。广告语和诗歌里常用。
① The poem uses alliteration.
= 那首诗用了头韵。
use alliteration = 运用头韵
② "Big brown bear" is alliteration.
= 「big brown bear」就是头韵。
③ Alliteration makes slogans catchy.
= 头韵让口号更上口。
词族：
alliterative = 押头韵的
近义对照：
alliteration = 头韵（词首辅音相同）
assonance = 谐元韵（元音相同）
rhyme = 押韵（词尾相同）

allium

plant alliums = 种大花葱
② Onions and garlic are alliums.
= 洋葱和大蒜都属葱属。
③ Alliums flower in early summer.
= 葱属植物初夏开花。

植物学与园艺用词。

onion = 洋葱
garlic = 大蒜
leek = 韭葱

allocate

allocate resources = 分配资源

allochthonous
核心：地质学形容词，指"外来的"——岩层或沉积物不是在现在这个位置
形成的，而是被搬运过来的。反义是 autochthonous（原地生成的）。
生态学里也用它说外来输入的有机质。
① The rocks are allochthonous.
= 那些岩层是外来的。
② An allochthonous block sits on native strata.
= 一块外来岩体压在原生地层上。
allochthonous block = 外来岩块
③ Allochthonous carbon enters the lake from land.
= 外源碳从陆地进入湖泊。
allochthonous carbon = 外源碳
注意语域：
地质学与生态学术语。
反义对照：
allochthonous = 外来的（搬运而来）
autochthonous = 原地的（就地生成）

allomorph
核心：语言学术语，指"语素变体"——同一个语素在不同环境下的不同
读法或写法。英语复数词尾读成三种音，就是同一个语素的三个变体。
① The plural has three allomorphs.
= 复数语素有三个变体。
three allomorphs = 三个语素变体
② Allomorphs are conditioned by context.
= 语素变体由语境决定。
conditioned by context = 受语境制约
③ These forms are allomorphs of one morpheme.
= 这些形式是同一语素的变体。
注意语域：
形态学术语。
同构词对照：
allomorph = 语素变体（形态层面）
allophone = 音位变体（语音层面）
morpheme = 语素（最小意义单位）

allophone
核心：语音学术语，指"音位变体"——同一个音位在不同位置上的实际
读法差别，母语者一般听不出，换了也不会造成词义变化。
① The two sounds are allophones.
= 那两个音是同一音位的变体。
② Aspiration produces an allophone here.
= 送气在这里产生一个音位变体。
produce an allophone = 产生音位变体
③ Allophones never contrast meaning.
= 音位变体不区别词义。
never contrast meaning = 不区别意义
注意语域：
音系学术语。
注意别混：
allophone = 音位变体（不辨义）
phoneme = 音位（能辨义的最小单位）

allosaurus

利爪，是当时北美的顶级掠食者。复数 allosauruses 或 allosauri。
① The museum displays an allosaurus skeleton.
= 博物馆展出了一具异特龙骨架。
allosaurus skeleton = 异特龙骨架
② Allosaurus hunted large plant-eaters.
= 异特龙捕食大型植食动物。
③ An allosaurus could reach nine metres.
= 异特龙能长到九米。
注意语域：
古生物学名称。

allosaurus = 异特龙（侏罗纪，北美）
tyrannosaurus = 霸王龙（白垩纪，更晚更大）

allot
核心：指按份额"分配、拨给"，正式。介词用 to。
注意拼写要双写 t。
① Ten minutes were allotted to each speaker.
= 每位发言人分到十分钟。
allot to = 分配给
② Funds were allotted for repairs.
= 拨了款用于维修。
allot for = 拨给…用
③ Use your allotted time well.
= 用好分给你的时间。
allotted time = 规定时间
注意拼写：allotted 双写 t。

allot = 按份分配（正式）

allotment
核心：两条线：一是"分配的份额"，二是英式特有的"市民菜园"——
政府划给居民种菜的小块地。第二条在英国文化里很常见。
① He grows vegetables on his allotment.
= 他在自己的菜园地里种菜。
allotment = 市民菜园（英式）
② Each got an allotment of shares.
= 每人分到一份股票。
an allotment of = 一份配额
③ The time allotment is 20 minutes.
= 分配的时间是二十分钟。
time allotment = 时间配额
词族：allot = 分配
注意：allotted 双写 t。
注意英美差别：
市民菜园这个意思美式没有。

allotrope
核心：化学名词，指"同素异形体"——同一种元素因为原子排列方式不同
而形成的不同单质。石墨和金刚石都是碳的同素异形体，性质天差地别。
这个现象叫 allotropy。注意跟 allot（分配）毫无关系。
① Diamond and graphite are allotropes of carbon.
= 金刚石和石墨是碳的同素异形体。
allotropes of carbon = 碳的同素异形体
② Oxygen has two common allotropes.
= 氧有两种常见的同素异形体。
③ Allotropy explains their different hardness.
= 同素异形现象解释了两者硬度的差别。
allotropy = 同素异形现象
注意语域：
化学术语。
注意别混：
allotrope = 同素异形体（化学）
allot = 分配（动词，毫不相干）

allow

不能说 allow someone doing。另有"留出余量"的义。
① They don't allow smoking here.
= 这里不许吸烟。
allow doing = 允许某行为
② She allowed me to leave.
= 她准我走了。
allow someone to do = 准许某人做
③ You're not allowed to park here.
= 这里不许停车。
be allowed to = 被允许
④ Allow two hours for the journey.
= 路上要留出两小时。
这里：
allow = 预留
⑤ Allow for delays.
= 把延误考虑进去。
allow for = 考虑到
注意：不说 allow someone doing。
⑥ The rules allow of no exception.
= 那些规定不容例外。
allow of = 容许有（正式，多用于否定）

alloy
核心：指两种以上金属熔合成的"合金"。动词义是"熔合"，也有比喻义

allspice

a pinch of allspice = 一撮多香果粉
