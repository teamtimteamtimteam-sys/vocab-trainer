# 词头清单（牛津高阶）

把牛津高阶第 10 版的词头文件放在这个目录里，文件名随意，
`scripts/coverage.py` 会自动认出 `.txt` 和 `.csv`。

## 为什么需要它

在此之前，B 词表每个字母段的目标清单都是我凭记忆列的 —— 清单本身就短，
跑差集只能证明「我列的都收了」，不能证明「我列全了」，于是反复出现
「宣布收全、实际漏三成」。已经发生四次，四次都是用户发现的：

- a 段初次只收了 10%
- ab- 段只收了 31%
- ao- 和 aa- 整段跳过
- as- 段宣布 77 条，实际应有 110 条

有了这份文件，收词完整性就从「靠我记性」变成机器检查。

## 格式要求

**txt**：一行一个词头，空行和 `#` 开头的行会被跳过。
**csv**：自动取第一列作为词头；如果首行是表头（含 headword / word / entry
等字样）会被跳过。

两种格式都不需要预先排序或去重，脚本会处理。
大小写、重音字母、连字符、多词条目都能正确对齐 —— 比对时用的是
`scripts/wordkey.py` 里那套按词排序的归一化规则。
