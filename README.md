# 背单词 · iPad mini app

纯前端单文件 PWA，数据全部存在设备本地（IndexedDB）。

## 在 iPad 上安装

1. 把 `index.html` 传到 iPad（AirDrop / iCloud Drive / 邮件都行）
2. 用 **Safari** 打开
3. 分享菜单 → **添加到主屏幕**
4. **以后一律从主屏幕图标进入**

> 第 4 步是硬性要求：加到主屏幕的 Web App 有自己独立的存储容器，不受 Safari
> 「连续 7 天无交互即清除脚本可写存储」的限制；用 Safari 标签页打开则不享受该豁免。
> 删除主屏幕图标会一并删除数据 —— 所以请定期用「设置 → 导出备份 JSON」备份。

## 在 Mac 上开发预览

`~/.claude/launch.json` 里有 `vocab-trainer` 配置（python3 http.server，端口 8413）。
iPad 同一 Wi-Fi 下访问 `http://<Mac 的 IP>:8413` 即可实时预览。

## 词表格式

三条硬规则：

1. 词条之间用**一个空行**分隔
2. 每个词条**第一行只写单词本身**
3. 每个例句以 **①②③** 开头，**紧跟一行以 `=` 开头**写中文翻译

其余内容（`这里：` / `核心就是：` / 词尾总结等）随意书写，会原样保留并统一排版。
其中形如 `word = 释义` 的**等式行**会被自动识别并高亮。

文件存为 **UTF-8 编码的 .txt**。导入前 App 会做格式自检并报出问题行号。

参见 `示例词表.txt`。

## 规则速查

| 项目 | 设定 |
|---|---|
| 分组 | 严格 50 词一组；不满 50 的进暂存区，下次导入自动补满 |
| 记忆曲线 | 整组背完后第 **1 / 2 / 4 / 7 / 15 / 30** 天各复习一次，共 6 轮 |
| 每日复习配额 | 5 组（逾期优先排序，超出部分不计入解锁条件） |
| 门禁 | 当日配额未清完则**锁定背诵**，无强制解锁入口 |
| 背诵节奏 | 一次只背一组，一天只背一组 |
| 复习判定 | 「记不清」的词展开全部内容，并进入本组下一轮，直到全部「还记得」 |
| 一天的分界 | 凌晨 **4:00** |
| 走完 6 轮 | 标记「已掌握」并归档，可在组列表手动重温 |

改这些参数：`index.html` 顶部的 `GROUP_SIZE` / `INTERVALS` / `DAILY_CAP` / `DAY_START`。
